## Skills integration

- App local cache에 Skills을 위한 디렉토리 구조를 생성
- AppCache 기준
  ./assistants/skills/ # per-assistant skills
  ./skills/ # global skills

- global skills는 초기에 기본으로 생성되며 https://github.com/fritzprix/skills로부터 다운받는다
  - donwload
  - locate the skills root
    - navigate directory tree from the root to the leaf
    - when SKILL.md is found, it is specific skill directory
    - ../ to the parent directory is the root of the skill
  - move to ./skills
- assistants skills는 global skills를 override하며 assistant의 권한을 추가할 수 있다.
  - AssistantEditor.tsx를 통해서 global skills에 있는 것을 check하여 선택 추가할 수 있음
  - 그 외 skill folder를 drag and drop하여 폴더를 추가할 수 있음
  - override check box를 통해 global skill을 override 할 수 있음
