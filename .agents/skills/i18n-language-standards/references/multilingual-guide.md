# Multilingual Standards Guide (ja, zh, de, fr, es, pt)

Guidelines for translating LibrAgent user interface text across supported target languages.

## 1. Japanese (`ja`)
- Avoid excessive katakana transliterations for concepts with natural native terms (e.g. `デフォルトLLM` → `既定のAIモデル`).
- Use polite standard desktop software phrasing (`です/ます` or clean noun phrases for titles).
- Match macOS/Windows localization conventions.

## 2. Simplified Chinese (`zh`)
- Use concise standard mainland UI terminology (`默认AI模型`, `自动摘要（推荐）`, `初始响应速度格式`).
- Keep punctuation clean (full-width Chinese punctuation).

## 3. German (`de`)
- Capitalize all nouns strictly in accordance with Duden conventions.
- Maintain formal register (`Sie`, `Ihre`).
- Translate compound technical nouns cleanly without hyphen explosion (`Standard-KI-Modell`, `Automatisierungsregeln`).

## 4. French (`fr`)
- Prefer clear verbal constructions over nominal clusters (`Conserve uniquement les N derniers messages`).
- Use standardized French software vocabulary (`Modèle d'IA par défaut`, `Résumé automatique`).

## 5. Spanish (`es`)
- Use standard pan-Spanish technical terminology understood across Spain and Latin America (`Modelo de IA predeterminado`, `Reglas de automatización`).
- Prefer active, clear instructions (`Active esta opción para...`).

## 6. Portuguese (`pt`)
- Use clear standard Brazilian and European Portuguese technical conventions (`Modelo de IA padrão`, `Resumo automático`).
- Maintain consistent terminology across all settings tabs.
