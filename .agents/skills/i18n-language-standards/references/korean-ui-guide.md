# 명확한 한국어 표준 UI 작성 가이드 (LibrAgent)

LibrAgent 데스크톱 앱의 사용자 인터페이스(UI), 설정 화면, 안내 문구에 적용하는 국어 표준 가이드입니다.

## 핵심 작성 원칙

1. **직관적인 일상 기술 용어 우선**:
   - 전문 엔지니어링 은어나 영문 직역 투어를 피하고, 일반 사용자(Layman)가 첫눈에 이해할 수 있는 단어를 사용합니다.
   - ❌ `기본 LLM`, `대체 LLM` → ✅ `기본 AI 모델`, `예비 AI 모델`
   - ❌ `프리필 성능 형식` → ✅ `첫 응답 반응 속도 형식`
   - ❌ `슬라이딩 윈도우`, `컴팩트` → ✅ `최근 메시지만 유지`, `대화 자동 요약 (권장)`
   - ❌ `자동화 거버넌스` → ✅ `자동화 실행 규칙`
   - ❌ `Diff 컨텍스트 라인` → ✅ `코드 변경 비교 줄 수`

2. **번역투 및 피동형 배제**:
   - 불필요한 수동태(`~되어지다`, `~유지되다`, `~제공되어집니다`) 대신 능동형 종결을 씁니다.
   - ❌ *세션 데이터가 빠른 메모리에 유지되어집니다.*
   - ✅ *세션 데이터를 빠른 메모리에 보관합니다.*

3. **내부 코드 및 함수 식별자 노출 금지**:
   - 개발자 코드 파라미터나 API 함수명을 사용자 설명에 절대 노출하지 않습니다.
   - ❌ `createSession에 browser="userChrome"으로...` → ✅ `현재 Chrome 브라우저의 로그인 상태를 함께 사용합니다.`
   - ❌ `awaitAgent와 같은 장시간 실행...` → ✅ `서브 에이전트 실행처럼 오래 걸리는 작업...`
   - ❌ `pollProcess 대기 중에...` → ✅ `결과 출력을 대기하며...`

4. **단문 위주의 명확한 종결**:
   - 한 문장에 복수의 접속사를 중첩하지 않고, 1~2개의 구체적인 사실만 명확하게 서술합니다.
   - 명사형 나열 종결(`~하기`, `~제어`)보다 자연스러운 설명형 문장(`~합니다`, `~설정하세요`)을 권장합니다.
