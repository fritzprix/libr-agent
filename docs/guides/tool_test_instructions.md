# AI Agent Tool Testing Instructions

## 목표

`execute_windows_cmd` 도구의 안정성과 타임아웃 문제 해결 여부를 검증합니다. 특히 `PersistentShell`의 `read_line_lossy` 수정 사항이 제대로 동작하여 데이터 손실 없이 명령이 수행되는지 확인합니다.

## 테스트 절차

다음 명령들을 순차적으로 실행하여 각 단계가 정상적으로 완료되는지 확인해 주세요.

### 1. 상태 유지 및 기본 동작 확인

1. `cd $env:TEMP` 실행
2. `Get-Location` 실행
   - **기대 결과**: 현재 경로가 TEMP 폴더로 변경되어 있어야 합니다.

### 2. 반복 실행 부하 테스트 (타임아웃 검증)

이전에는 약 10~15회 실행 후 타임아웃이 발생하는 문제가 있었습니다. 이를 검증하기 위해 다음을 수행합니다.

1. 다음 명령을 **20회 이상** 연속으로 호출하세요. (루프가 아닌 개별 도구 호출로 수행)
   - 명령어: `Write-Output "Iteration check: $(Get-Date)"`
2. **기대 결과**:
   - 모든 호출이 1초 이내에 즉시 반환되어야 합니다.
   - 30초 동안 멈추거나 타임아웃 에러가 발생하면 안 됩니다.

### 3. 대량 출력 및 에러 스트림 혼합 테스트

Race condition이 발생하기 쉬운 상황을 연출합니다.

1. 다음 명령 실행:

   ```powershell
   1..100 | ForEach-Object { 
       Write-Output "Stdout line $_"; 
       if ($_ % 10 -eq 0) { Write-Error "Stderr line $_" } 
   }
   ```

2. **기대 결과**:
   - Stdout과 Stderr가 모두 캡처되어야 합니다.
   - 프로세스가 멈추지 않고 종료되어야 합니다.
