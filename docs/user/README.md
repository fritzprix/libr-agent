### 온보딩 한줄

1. **Settings → AI & Models → Provider API Keys** → **Save Changes**
2. **Chat**에서 어시스턴트 카드로 세션 시작
3. MCP는 **Extensions**
4. 반복 작업은 **Playbooks** / **Scheduled Tasks**
