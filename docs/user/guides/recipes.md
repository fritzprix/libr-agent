# 솔루션 레시피 (Solution Recipes)

솔루션 레시피는 특정 사용 시나리오에 필요한 **MCP 서버 프리셋, 맞춤 어시스턴트, 예약 작업(Scheduled Task)**을 클릭 한 번으로 일괄 설치·설정해 주는 원클릭 워크플로우 템플릿입니다.

---

## 🚀 빠른 시작

1. **Chat 홈 화면**의 추천 카드(**"5분 만에 만드는 나만의 모닝 브리핑 비서"**) 또는 **Scheduled Tasks** 화면의 워크스루 버튼을 클릭합니다.
2. 안내에 따라 설치할 MCP 도구 프리셋(`hn`, `yahoo-finance`)을 확인합니다.
3. **설치(Install)**를 진행하면 전용 어시스턴트와 예약 작업이 한 번에 자동 생성됩니다.
4. 설치 완료 후 즉시 테스트 프롬프트로 실행하거나, 예약된 시간에 자동으로 동작하도록 둘 수 있습니다.

---

## ☕ 모닝 브리핑 레시피 (Morning Briefing)

매일 아침 **Hacker News**의 최신 기술 트렌드와 **Yahoo Finance**의 주요 금융 시장 지표를 결합하여 일일 요약 보고서를 전달하는 자동화 레시피입니다.

### 설치되는 구성 요소

| 구성 요소           | 상세 내용                                                                                          |
| ------------------- | -------------------------------------------------------------------------------------------------- |
| **MCP 프리셋**      | `hn` (Hacker News 피드 수집) + `yahoo-finance` (주가 및 환율 데이터)                               |
| **맞춤 어시스턴트** | **"모닝 브리핑 비서"** (`Morning Briefing Assistant`) — 일일 브리핑 보고서 작성에 특화된 지침 탑재 |
| **예약 작업**       | **"매일 아침 9시 모닝 브리핑"** — 매일 아침 9:00 정기 실행 (`0 9 * * *`)                           |
| **실행 모드**       | `YOLO` (배경 실행 시 별도 승인 팝업 없이 전자동 완료)                                              |

### 동작 흐름

매일 아침 9시가 되면:

1. `hn` MCP 도구를 통해 Hacker News 상위 기술 뉴스를 읽습니다.
2. `yahoo-finance` 도구를 통해 S&P 500, 나스닥 및 주요 환율 지표를 조회합니다.
3. 종합된 정보를 바탕으로 읽기 쉬운 한국어 마크다운 리포트를 작성합니다.

---

## ⚙️ 맞춤 설정 및 수정

설치된 레시피의 일정이나 내용을 바꾸고 싶다면 언제든 수정할 수 있습니다:

- **실행 시간 변경**: **Scheduled Tasks** 메뉴에서 "매일 아침 9시 모닝 브리핑" 작업의 일정을 변경합니다.
- **보고서 내용 조정**: **Assistants** 메뉴에서 "모닝 브리핑 비서"의 시스템 지침을 원하는 스타일로 수정합니다.
- **지금 바로 실행**: 설치 완료 대화상자에서 제공되는 테스트 프롬프트를 사용하여 바로 결과를 확인합니다.

---

## 💡 나만의 워크플로우를 직접 만들고 싶다면?

제공되는 레시피 외에 다른 목적의 자동화가 필요하다면, 다음 기능을 조합하여 손쉽게 동일한 자동화를 구축할 수 있습니다:

1. **Extensions**: 필요한 MCP 서버 프리셋(예: GitHub, Filesystem 등) 추가
2. **Assistants**: 해당 작업 목적에 맞는 시스템 지시어와 도구를 갖춘 전용 어시스턴트 생성
3. **Scheduled Tasks**: 원하는 주기(Cron)와 실행 모드로 예약 작업 등록
