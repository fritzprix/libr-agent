# 브라우저 자동화 (Browser Sidecar)

LibrAgent는 에이전트가 웹사이트를 탐색하고, 필요한 정보를 검색·수집하며, 화면 스크린샷을 분석할 수 있도록 강력한 브라우저 자동화 기능을 제공합니다.

---

## 🛡️ 완벽한 프로세스 격리와 안정성

웹 브라우징 중 복잡한 웹페이지나 스크립트 오류가 발생하더라도 사용자의 작업 환경을 안전하게 보호합니다:

- **독립된 샌드박스 실행**: 브라우저 자동화는 LibrAgent 데스크톱 앱 본체와 분리된 독립 프로세스에서 안전하게 실행됩니다. 웹페이지가 충돌하거나 과도한 메모리를 사용해도 앱 본체는 안전합니다.
- **고정 에이전트 프로필**: 기본값인 **에이전트 전용 브라우저**는 이 기기의 LibrAgent 전용 프로필을 다시 사용합니다. 그 브라우저 *안에서* 한 로그인은 이후에도 유지되며, **Settings → System → 에이전트 브라우저 → 에이전트 브라우저 데이터 지우기**로 삭제할 수 있습니다. 평소 쓰는 Chrome과는 별개입니다. 에이전트 전용 브라우저가 떠 있는 동안 여러 채팅이 같은 로그인·쿠키를 공유합니다.

---

## 일상 Chrome 연동 (로그인 상태 그대로 사용)

에이전트가 별도의 빈 브라우저를 띄우는 대신, **평소 쓰는 Personal Chrome**의 탭을 직접 제어할 수 있습니다.

### 💡 일반 사용자가 얻는 핵심 혜택

- **로그인 상태 유지**: 이미 로그인된 네이버, 구글, 사내 인트라넷을 그대로 사용합니다. 비밀번호를 다시 입력할 필요가 없습니다.
- **보안 사이트 클릭/입력 지원**: 엄격한 보안 정책이 적용된 사이트에서도 버튼 클릭과 텍스트 입력이 더 안정적으로 동작합니다.
- **페이지 원본 저장**: 필요한 웹페이지의 전체 HTML을 세션 작업 폴더에 파일로 저장해 오프라인에서도 확인할 수 있습니다.

| 실행 모드 | 특징 | 적합한 작업 |
| --- | --- | --- |
| **에이전트 전용 브라우저** (기본) | LibrAgent 전용 격리 브라우저 | 일반 웹 검색, 공개 문서 조사, 독립된 샌드박스 작업 |
| **Personal Chrome** (확장 연동) | 평소 쓰는 내 Chrome 브라우저 | 로그인 세션이 필요한 개인화 작업, 사내 서비스 조회 |

## 🚀 일상 Chrome 1분 연동 방법

> [!TIP]
> **Chrome 웹 스토어 정식 출시 예정 (TBD)**  
> 현재 Chrome Web Store 공식 등록 심사가 진행 중입니다. 스토어 링크 출시 전까지는 아래의 1분 로컬 등록(`Load unpacked`) 방식으로 즉시 연결하여 사용할 수 있습니다.

1. **경로 복사**: 사이드바 **Settings → System → 에이전트 브라우저**에서 Chrome 확장 프로그램 경로를 확인합니다.
2. **확장 프로그램 등록**:
   - Chrome 주소창에 `chrome://extensions`를 입력합니다.
   - 우측 상단의 **개발자 모드**를 켭니다.
   - **압축해제된 확장 프로그램을 로드합니다**를 클릭하고 복사한 경로(`chrome-extension`)를 선택합니다.
3. **작업 지시**:
   - 대화창에서 평소처럼 지시합니다:
     ```
     현재 내 Chrome 브라우저에서 장바구니 페이지 확인해줘.
     ```
   - 에이전트가 Personal Chrome 모드로 전환하여 현재 탭을 제어합니다.

> [!NOTE]
> - 한 번 등록해 두면 LibrAgent를 재시작해도 자동으로 다시 연결됩니다.
> - 에이전트 채팅마다 활성 브라우저는 하나뿐입니다. 에이전트 전용 브라우저와 Personal Chrome을 바꾸면 이전 브라우저 연결은 자동으로 정리됩니다.

## 🌐 주요 기능

| 기능 | 설명 |
| --- | --- |
| **페이지 방문 및 탐색** | 대상 웹사이트에 접속해 로딩이 끝나면 본문을 확인합니다 |
| **화면 캡처** | 보이는 화면 또는 전체 페이지를 이미지로 캡처해 시각적으로 검증합니다 |
| **콘솔 및 상태 모니터링** | 페이지 오류와 네트워크 상태를 파악해 문제 분석을 돕습니다 |
| **클릭·입력** | 링크 클릭, 스크롤, 텍스트 입력 등 자연스러운 웹 서핑을 수행합니다 |

---

## 🎯 대표적인 활용 시나리오

1. **최신 기술 문서 및 릴리즈 노트 조사**:
   - 실시간 웹페이지를 직접 방문하여 최신 라이브러리 문서나 뉴스를 요약합니다.
2. **웹 UI 개발 결과 검증**:
   - 로컬 개발 서버(`http://localhost:3000`)에 접속하여 UI가 의도대로 렌더링되었는지 스크린샷으로 확인합니다.
3. **정기 브리핑 자동화**:
   - 예약 작업(Scheduled Tasks)과 결합하여 매일 특정 대시보드나 주요 사이트를 방문하여 일일 요약을 받아봅니다.

---

## 💡 유의 사항

- 첫 웹 브라우징 실행 시 백그라운드 브라우저 엔진이 초기화되므로 최초 1회에 한해 수 초의 준비 시간이 소요될 수 있습니다.
