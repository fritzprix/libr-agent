# 브라우저 자동화

LibrAgent 에이전트는 웹을 열고, 내용을 읽고, 화면을 캡처할 수 있습니다.

---

## 에이전트 전용 브라우저 (기본)

기본값은 LibrAgent가 따로 띄우는 **에이전트 전용 브라우저**입니다.

- 앱과 분리된 프로세스에서 돌아가서, 페이지가 무겁거나 깨져도 LibrAgent 본체가 안전하게 유지됩니다.
- 이 브라우저 안에서 한 로그인은 기기에 남습니다. **Settings → System → 에이전트 브라우저 → 에이전트 브라우저 데이터 지우기**로 지울 수 있습니다.
- 평소 쓰는 Chrome과는 별개입니다.

공개 검색·문서 조사·샌드박스 작업에는 이 모드면 충분합니다.

---

## 일상 Chrome (필요할 때만)

이미 로그인해 둔 장바구니, 메일, 사내망, 개인 대시보드를 그대로 쓰려면 **일상 Chrome** 확장을 설치하세요.

| 구분 | 에이전트 전용 | 일상 Chrome |
| ---- | ------------- | ----------- |
| 로그인 | LibrAgent 전용 프로필 | 평소 Chrome 계정·쿠키 |
| 적합한 작업 | 공개 웹 조사 | 개인·사내 로그인 사이트 |
| 설치 | 불필요 | Chrome 확장 1회 |

### 설치 (Chrome 웹 스토어)

1. LibrAgent 데스크톱 앱을 켭니다.
2. Chrome에서 **[LibrAgent Browser Bridge](https://chromewebstore.google.com/detail/libragent-browser-bridge/eponcjengahlpkgbaolhemhmckopmfbe)** 를 설치합니다.
3. 툴바 아이콘을 열어 상태가 **연결됨**인지 확인합니다.  
   「LibrAgent not running」이면 앱을 켠 뒤 잠시 기다리면 됩니다.
4. 채팅에서 예를 들어 이렇게 요청합니다:
   ```
   지금 쓰는 Chrome에서 장바구니 확인해 줘.
   ```

앱 안 **Settings → System → 일상 Chrome**에도 같은 스토어 설치 버튼이 있습니다.

### 로컬 폴더로 설치 (개발용)

리포의 `chrome-extension/` 폴더를 쓰려면 Settings에서 경로를 복사한 뒤, Chrome `chrome://extensions` → 개발자 모드 → 「압축해제된 확장 프로그램을 로드합니다」를 선택하세요.

> [!NOTE]
>
> - 한 번 설치하면 LibrAgent를 다시 켜도 확장이 스스로 다시 연결됩니다.
> - 한 채팅에는 브라우저 연결이 하나만 있습니다. 전용 브라우저와 일상 Chrome을 바꾸면 이전 연결은 정리됩니다.
> - 확장은 **이 컴퓨터의 LibrAgent와 Chrome**만 연결합니다. 브라우징 기록을 LibrAgent 클라우드로 보내지 않습니다.

## 무엇을 할 수 있나

| 기능 | 에이전트 전용 | 일상 Chrome |
| ---- | ------------- | ----------- |
| 페이지 열기·이동 | ✅ | ✅ |
| 본문 읽기 | ✅ | ✅ |
| 클릭·입력·스크롤 | ✅ | ✅ (보안이 강한 사이트에서도 동작) |
| 화면 캡처 | ✅ (보이는 영역 / 전체 페이지) | ✅ (보이는 영역만) |
| 콘솔 로그 확인 | ✅ | ❌ (아직 지원하지 않음) |
| 내 Chrome 로그인 사용 | ❌ | ✅ |

일상 Chrome으로 자주 쓰는 예: 로그인된 쇼핑·메일·GitHub 확인, 사내 대시보드 열기, 보이는 탭 캡처, 폼 클릭·입력.

---

## 활용 예시

1. **최신 문서·뉴스 조사** — 공개 페이지를 열어 요약합니다.
2. **로컬 UI 확인** — `http://localhost:3000` 같은 개발 서버를 열고 화면을 캡처합니다.
3. **정기 브리핑** — 예약 작업과 함께 매일 같은 사이트를 열어 요약합니다.
