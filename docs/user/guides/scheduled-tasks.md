# 예약 작업 (Scheduled Tasks)

예약 작업(Scheduled Tasks)은 사용자가 지정한 일정(Cron 표현식)에 따라 에이전트가 백그라운드에서 자동으로 프롬프트를 실행하고 작업을 수행하는 기능입니다.

---

## 🌟 주요 기능

- **Cron 기반 주기적 실행**: 원하는 시간, 매일 아침, 매주 특정 요일 등 정밀한 스케줄링 지원
- **실행 모드 지정**:
  - `YOLO`: 표준 도구 호출을 확인 팝업 없이 자동 승인
  - `Unsafe`: 셸 명령어 및 파일 변경을 포함한 모든 작업을 확인 창 없이 완전 자율 실행 (Full Auto, 시스템 정밀 점검용)
  - `Normal`: 중요한 시스템 변경 시 사용자 승인 대기
- **전용 어시스턴트 매핑**: 작업 특성에 맞는 시스템 지침과 도구 권한을 가진 어시스턴트 지정 가능
- **스타터 템플릿 제공**: 자주 사용되는 유용한 자동화 템플릿 원클릭 설치 지원

---

## 🚀 기본 스타터 템플릿

Scheduled Tasks 화면에서 다음 템플릿을 바로 추가할 수 있습니다:

| 템플릿명                             | 실행 주기                   | 실행 모드            | 주요 내용                                                                                      |
| ------------------------------------ | --------------------------- | -------------------- | ---------------------------------------------------------------------------------------------- |
| **내 PC 헬스 & 보안 일일 점검**      | 매일 자정 (`0 0 * * *`)     | `Unsafe` (Full Auto) | 디스크 잔여 용량, 장시간 실행 프로세스, 미커밋 Git 상태 및 패키지 취약점 종합 점검 리포트 생성 |
| **웹사이트 변경 및 헤드라인 브리핑** | 매일 아침 9시 (`0 9 * * *`) | `YOLO`               | 브라우저 도구로 Hacker News 등 기술 사이트를 방문하여 핵심 헤드라인 3줄 요약 브리핑            |

---

## ⚙️ 예약 작업 생성 및 관리

1. **사이드바에서 Scheduled Tasks 이동** (시계 아이콘)
2. **새 작업 만들기 (Add Task)** 클릭
3. **설정 항목 입력**:
   - **Task Name**: 작업의 이름 (예: `일일 백업 점검`)
   - **Cron Expression**: 실행 주기 (예: `0 9 * * 1-5` — 평일 오전 9시)
   - **Prompt Message**: 에이전트에게 내릴 구체적인 작업 지시
   - **Assistant**: 작업을 수행할 어시스턴트 선택
   - **Execution Mode**: 무인 실행 강도에 따라 `YOLO`, `Unsafe`, 또는 `Normal` 선택
4. **저장 및 활성화**:
   - 작업 카드 우측의 토글 스위치로 언제든지 활성화/비활성화할 수 있습니다.
   - **Run Now(즉시 실행)** 버튼으로 스케줄 시간과 무관하게 동작을 즉시 테스트할 수 있습니다.

---

## 💡 유의 사항

- 데스크톱 로컬 앱 환경이므로, 예약 작업이 실행되려면 시스템이 켜져 있고 LibrAgent가 백그라운드에서 구동 중이어야 합니다.
- 파일 수정이나 셸 명령어 실행이 포함된 완전 무인 작업의 경우 `YOLO` 또는 `Unsafe` 모드로 설정해야 승인 대기 없이 완결됩니다.
