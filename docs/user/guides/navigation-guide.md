# 화면 네비게이션 가이드

LibrAgent 데스크톱 애플리케이션의 화면 레이아웃과 좌측 사이드바 구성을 이해하고 원하는 작업 화면으로 빠르게 이동하는 방법을 안내합니다.

---

## 🧭 좌측 메인 사이드바 구성

LibrAgent의 주요 기능은 좌측 사이드바를 통해 원클릭으로 접근할 수 있습니다.

```
┌──────────────────┬────────────────────────────────────────────────────────┐
│  [📜 History]    │ 대화 기록: 지난 세션 시간순 탐색, 검색 및 세션 복원     │
│  [🔖 Bookmarked] │ 북마크 세션: 중요한 대화 세션 모아보기                  │
│  [🤖 Chat]       │ 에이전트 작업장: 실시간 대화 및 도구 실행 관찰          │
├──────────────────┼────────────────────────────────────────────────────────┤
│  [🧠 Knowledge]  │ 지식 베이스: 영구 메모리 및 시각적 지식 네트워크 그래프  │
│  [👥 Assistants] │ 맞춤 에이전트: 역할별 시스템 프롬프트 및 도구 설정     │
│  [📋 Playbooks]  │ 플레이북: 검증된 반복 워크플로우 템플릿 관리            │
│  [🧩 Extensions] │ 확장 기능: 외부 MCP 서버 및 스킬 관리 (/mcp-servers)   │
│  [🏢 Org]        │ 조직 관리: 멀티 에이전트 팀 및 계층 구조 모니터링      │
│  [⏱️ Scheduled]  │ 예약 작업: Cron 기반 백그라운드 자동화 일정 등록       │
├──────────────────┼────────────────────────────────────────────────────────┤
│  [⚙️ Settings]   │ 환경 설정: AI 모델 API 키, 테마 및 시스템 설정          │
└──────────────────┴────────────────────────────────────────────────────────┘
```

> [!NOTE]
> **솔루션 레시피(Recipes)는 어디에 있나요?**  
> 레시피는 사이드바 메뉴가 아닌 **Chat 홈 화면의 추천 카드("5분 만에 만드는 나만의 모닝 브리핑 비서")** 또는 **Scheduled Tasks 화면의 워크스루 버튼**을 통해 실행할 수 있는 대화형 설치 마법사입니다.

---

## 🤖 1. 메인 작업장 (Main)

### 대화 기록 (History & Bookmarked)

- 모든 지난 대화 내역을 시간순으로 조회하거나 키워드로 검색할 수 있습니다.
- 북마크 아이콘을 눌러 중요한 세션만 별도로 모아볼 수 있습니다.

### 에이전트 작업장 (Chat)

- AI 에이전트와 실시간으로 대화하며 실제 코딩, 리서치, 자동화 작업을 위임하는 기본 화면입니다.
- 에이전트의 사고 과정(Thinking), 파일 읽기/쓰기, 브라우징, 터미널 실행 과정을 카드 형태로 실시간 관찰할 수 있습니다.

---

## 📚 2. 라이브러리 관리 (Library)

### 지식 베이스 (Knowledge)

- 에이전트가 기억하거나 축적한 영구 지식 엔티티를 관리합니다.
- 시각적 인터랙티브 지식 네트워크 그래프를 통해 연결 관계를 직관적으로 탐색할 수 있습니다.

### 어시스턴트 (Assistants)

- 코딩 전문가, 리서치 비서, 번역 도우미 등 목적에 맞는 전용 에이전트 프로필을 생성·편집합니다.
- AI 모델(Claude, GPT, Gemini, Ollama 등), 시스템 지침, 사용할 도구를 개별 지정할 수 있습니다.

### 플레이북 (Playbooks)

- 성공적으로 완료된 다단계 작업 프롬프트를 템플릿으로 저장하여 재사용합니다.

### 확장 기능 (Extensions)

- Model Context Protocol(MCP) 도구 서버를 등록하고 상태를 제어합니다.
- 상단 탭에서 **Tools**(MCP 서버 관리)와 **Skills**(스킬 디렉터리 관리)를 전환할 수 있습니다. _(Settings가 아닌 Extensions 화면에서 관리됩니다)_

### 조직 관리 (Org)

- `teamwork`나 `org` 스킬로 구성된 정식 멀티 에이전트 팀과 구성원 계보를 시각적으로 확인합니다.

### 예약 작업 (Scheduled Tasks)

- 사람이 자리에 없어도 정해진 시간(매일 자정, 평일 오전 9시 등)에 에이전트가 스스로 작업을 수행하도록 Cron 스케줄을 설정합니다.

---

## ⚙️ 3. 시스템 설정 (Settings)

- **AI & Models**: Anthropic, OpenAI, Google Gemini, Ollama 등 제공자별 API 키 등록 및 기본 모델 설정
- **일반 설정**: UI 언어(한국어/영어), 다크/라이트 모드 테마 전환
- **보안 & 업데이트**: 세션 격리 상태 및 최신 앱 릴리즈 확인
