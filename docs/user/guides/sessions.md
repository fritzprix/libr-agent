# 세션 관리하기

> 대화 단위가 **세션**입니다. 시작·북마크·삭제·검색은 사이드바 **Chat** / **History** / **Bookmarked**에서 합니다.

---

## 새 세션 시작

1. 사이드바 **Chat**
2. **Built-in Assistants** 또는 **My Assistants** 카드 클릭
3. 제목 **New Session** 초안에서 메시지 전송

「+ New Session」 단독 버튼으로 시작하지 않습니다.

---

## 북마크

중요한 세션을 빠르게 다시 열려면:

1. **History** 세션 카드의 북마크 아이콘을 켭니다.
2. 사이드바 **Bookmarked**, 또는 History의 bookmarked 필터로 모읍니다.

---

## 삭제

- 자식(하위 에이전트)이 **없으면**: 확인 후 해당 세션만 삭제.
- 자식이 **있으면**:
  - **모두 삭제** / **Delete all** (+N subagents) — 부모와 하위 함께 삭제
  - **이것만 삭제** / **Delete only this** (Subagents kept) — 부모만 삭제, 자식은 유지

복구되지 않습니다. 하위 에이전트 개념: [서브 에이전트](sub-agents.md)

---

## 검색 · 재개

**History**에서 이름/ID·내용을 **서버 검색**합니다 (커서 페이지네이션, 북마크/상태 필터). 카드를 열어 이어서 대화합니다.  
최근 전환한 세션은 메모리에 웜(Warm) 상태로 유지되어 세션 간 이동 시 대화 뷰가 재로드 지연 없이 즉시 전환됩니다.  
세션 중 Provider/Model은 Chat 피커로 **현재 세션만** 변경 가능합니다.

### 워크스페이스 재정의 · `/reload`

- 세션에 **workspace override**(커스텀 작업 폴더)를 지정한 경우, 디스크가 잠시 안 보여도 설정은 유지됩니다. 경로가 다시 보이면 그대로 사용합니다.
- 채팅에 **`/reload`** 를 입력하면 대화 기록은 유지한 채 워크스페이스 도구·스킬 목록만 새로고칩니다.

### 채팅 리치 콘텐츠

- **Mermaid**(` ```mermaid `)와 **LaTeX**(`$…$` / `$$…$$`)가 채팅 메시지, 결과 카드, 인터랙티브 마크다운 패널에서 렌더됩니다.
- 메시지 **복사** / **PDF 내보내기**도 다이어그램·수식을 유지합니다 (PDF는 Mermaid를 이미지로 넣고, 수식은 TeX 경로를 사용).

### 마지막 턴 다시 생성 (Regenerate)

세션이 **idle**(스트리밍 중이 아님)일 때, 최신 어시스턴트 메시지에 **Regenerate** 액션이 나타납니다. 완료된 그 턴을 버리고 직전 사용자 메시지부터 다시 생성합니다. 같은 프롬프트를 다시 붙여 넣지 않고 다른 답을 받을 때 쓰세요. 턴이 실패한 경우의 오류 경로 재시도는 그대로 있습니다.

## Docker 세션

**New Session** 초안에서 **Use Docker Container**를 켜면 세션의 셸 명령과 stdio MCP 서버가 내 컴퓨터가 아닌 컨테이너에서 실행됩니다.

- **기본 이미지**: 이미지를 지정하지 않으면(프리셋 **LibrAgent**) `ghcr.io/fritzprix/libragent-session:<버전>`을 사용합니다. bash, git, node(npm, npx), python3, uv(uvx)가 들어 있습니다. docker CLI와 빌드 도구는 없습니다.
- **크기**: 압축 다운로드 크기는 약 152 MB입니다(linux/amd64, linux/arm64). 첫 세션에서 한 번만 내려받습니다.
- **버전**: 태그는 LibrAgent 버전과 같습니다. 개발 빌드와 프리릴리스 빌드는 마지막 릴리스 버전의 태그를 사용합니다. 처음 게시되는 이미지는 LibrAgent 0.9.30용이며, 그 릴리스 전에 만든 개발 빌드에는 기본 이미지가 없습니다. 해당 이미지가 없으면 세션 시작이 이미지 이름을 알려 주는 오류로 실패합니다. 다른 이미지를 지정하면 계속할 수 있습니다.
- **다른 이미지**: 이미지 이름을 입력하거나 프리셋을 고릅니다. 세션은 이미지를 저장하므로 앱을 업데이트해도 바뀌지 않습니다. 도구에 필요한 런타임(예: `npx`)이 이미지에 없으면 도구를 시작할 때 세션이 이를 알려 줍니다.

### root 명령 (`asRoot`)

에이전트는 `asRoot`로 `runShell` 명령을 root로 실행할 수 있습니다. 예를 들어 시스템 패키지를 설치할 때(`apt-get install -y nodejs`) 사용합니다.

- **사용 범위**: LibrAgent가 세션용으로 만든 컨테이너에서만 됩니다. 내 컴퓨터에서 실행하는 세션이나 연결(attach)한 컨테이너에서는 `asRoot`를 거부하며 승인 카드도 띄우지 않습니다.
- **승인**: root라는 이유만으로 승인을 요청하지 않습니다(모든 실행 모드). root가 아니어도 강한 승인(hard approval)이 필요하거나 차단되는 명령은 root에서도 그대로 승인이 필요하거나 차단됩니다.
- **보호 장치**: 컨테이너는 `SETFCAP`, `MKNOD`, `NET_RAW` 권한 없이 `no-new-privileges`로 실행됩니다. root 명령이 끝날 때마다 LibrAgent는 그 명령이 남긴 프로세스를 멈추고 작업 공간 파일을 사용자에게 되돌립니다. setuid/setgid 비트와 장치 파일을 지우고, root 소유 파일의 소유자를 사용자로 바꿉니다.
- **작업 공간**: 컨테이너 세션의 작업 공간은 홈 디렉터리이거나 홈 디렉터리를 포함하는 폴더일 수 없습니다. 프로젝트 폴더를 선택하세요.

감수하는 위험:

- root 명령은 컨테이너 파일 시스템(프로그램, `/etc`)을 바꿀 수 있습니다. 이 변경은 세션 컨테이너 안에만 남고, LibrAgent가 컨테이너를 다시 만들면 사라집니다.
- 컨테이너가 사용자 계정으로 실행되므로, root가 아닌 명령도 작업 공간의 파일을 바꿀 수 있습니다.
- rootful Docker를 사용자 네임스페이스 재매핑(userns-remap) 없이 쓰면, 이 보호 장치로는 컨테이너를 벗어나는 커널 공격을 막지 못합니다.

## 내보내기

채팅 헤더 또는 History 카드의 **Export** 메뉴로 저장된 대화를 파일로 저장합니다.

- **Markdown (.md)** — 사람이 읽기 쉬운 대화 기록(생각 과정·도구 사용 요약 포함). 일상 공유·보관용으로 추천합니다.
- **ATIF (.json)** — **선택·고급**. 개발자·분석용 궤적 포맷입니다. 스크린샷 등 큰 미디어는 원문 대신 자리 표시만 들어갑니다. 자세한 내용은 [세션 내보내기](session-export.md)를 보세요.
- **보이는 대화 복사** (활성 채팅만) — 지금 화면에 보이는 대화를 클립보드로 복사합니다. 생각 과정은 빠지고 길이 제한이 있으며, Markdown 파일 내보내기와는 다릅니다.

진행 중인 세션도 그 시점의 스냅샷으로 내보낼 수 있습니다. 아직 스트리밍 중인 행은 제외됩니다.
