# 세션 내보내기 (Session Export)

진행한 에이전트 대화 내역과 작업 결과를 외부 파일로 저장하여 동료와 공유하거나 문서로 보관할 수 있습니다.

---

## 📦 지원 포맷

LibrAgent는 두 가지 포맷으로 세션 내보내기를 지원합니다:

### 1. Markdown (`.md`) — 일반 사용자용 (추천)

- 사람이 읽기 쉬운 문서로 저장합니다.
- **포함 내용**: 사용자의 요청, 에이전트의 답변, 실행된 도구 요약, 세션 중 생성된 핵심 결과물
- **추천 활용**: 회의록 공유, 작업 일지, 산출물 보관

### 2. ATIF (`.json`) — 선택·고급 (개발자·분석용)

- 에이전트 궤적(trajectory)을 기계가 읽기 좋은 JSON으로 저장합니다.
- 단계별 사고·도구 입출력을 자세히 남겨 **벤치마크·분석·재현**에 씁니다.
- 일상 공유·보관에는 보통 **Markdown**이면 충분합니다. ATIF는 필요할 때만 고르세요.

---

## 🧹 깔끔한 결과물 정제

LibrAgent는 원시 데이터베이스를 그대로 추출하지 않고, 불필요한 시스템 노이즈를 자동으로 걸러냅니다:

- **임시 조각 제거**: 실시간 타이핑 도중 발생한 조각 메시지 정리
- **시스템 유지 메시지 제외**: 대화 유지를 위해 내부적으로 오간 시스템 안내문 제거
- **재시도 잡음 필터링**: 일시적 통신 오류 등으로 인한 내부 재시도 로그 정제

따라서 내보낸 파일에는 실제 사용자와 에이전트가 나눈 유의미한 작업 결과만 깔끔하게 보존됩니다.

---

## 🚀 사용 방법

1. 대화창(Chat) 상단 툴바에서 **내보내기(Export)** 아이콘을 클릭합니다.
2. 원하는 포맷(**Markdown** 또는 선택적으로 **ATIF**)을 선택합니다.
3. 저장 위치를 선택하면 파일이 즉시 다운로드됩니다.
