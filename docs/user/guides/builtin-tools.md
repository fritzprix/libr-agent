# 내장 도구 안내 (Built-in Tools)

LibrAgent는 별도의 외부 도구 설치 없이도 코딩, 파일 조작, 웹 탐색, 화면 캡처, 시스템 명령 실행을 즉시 수행할 수 있는 **내장 도구(Built-in Tools)** 세트를 기본 제공합니다.

에이전트는 사용자의 질문이나 작업 지시를 받으면 상황에 맞는 최적의 내장 도구를 자율적으로 선택하여 실행합니다.

---

## 🛡️ 안전 제어 및 실행 승인 정책

에이전트의 도구 실행은 사용자의 통제 하에 안전하게 이루어집니다:

| 도구 분류              | 안전 정책                          | 주요 대상 작업                                                                  |
| ---------------------- | ---------------------------------- | ------------------------------------------------------------------------------- |
| **일반 읽기 도구**     | 자동 실행                          | 파일 내용 읽기, 웹페이지 텍스트 조회, 대화 기록 검색                            |
| **시스템 변경 도구**   | **사용자 승인 요청** (Normal 모드) | 셸 명령어 실행(`runShell`), 파일 생성 및 수정                                   |
| **데스크톱 제어 도구** | **사용자 승인 필수**               | 데스크톱 화면 캡처(`captureScreen`), 마우스/키보드 직접 제어(`computerControl`) |

> [!TIP]
> 백그라운드 무인 자동화(예: Scheduled Tasks)나 신뢰할 수 있는 세션에서는 실행 모드를 **YOLO** 또는 **Unsafe**로 설정하여 승인 팝업 없이 즉시 작업을 완료하도록 할 수 있습니다.

---

## 🛠️ 주요 내장 도구 분야

### 1. 작업 공간 및 파일 (`workspace`)

에이전트가 지정된 작업 디렉토리 내의 파일과 코드를 직접 읽고 수정합니다.

- **파일 읽기 및 검색**: 코드베이스나 텍스트 문서의 내용을 파악합니다.
- **정밀 라인 편집**: 파일 전체를 덮어쓰지 않고 필요한 코드 블록만 정확하게 수정합니다.
- **터미널 명령어 실행**: 빌드, 테스트 실행, 패키지 설치 등의 셸 명령을 실행하고 결과를 수집합니다.

### 2. 웹 브라우징 (`browser`)

독립된 브라우저 프로세스를 통해 실제 웹사이트에 접속합니다.

- **웹페이지 방문 및 내용 추출**: 최신 기술 문서, 블로그 포스트, 실시간 뉴스 본문을 읽어옵니다.
- **화면 스크린샷**: 웹페이지 레이아웃이나 시각적 결과를 캡처하여 확인합니다.

### 3. 미디어 및 컴퓨터 제어 (`media`, `desktop`)

시각적 분석과 운영체제 직접 제어가 필요할 때 사용됩니다.

- **화면 캡처**: 현재 모니터 화면을 캡처하여 오류 화면이나 UI 상태를 AI가 직접 확인합니다.
- **마우스 & 키보드 시뮬레이션**: GUI 앱 조작 등 마우스 클릭과 단축키 입력을 직접 시뮬레이션합니다. _(항상 사용자 승인 팝업이 표시됩니다)_

### 4. 계획 및 작업 관리 (`planning`, `scheduled_task`)

복잡한 다단계 작업을 체계적으로 완료하도록 돕습니다.

- **단계별 플래닝**: 거대한 작업을 작은 단위(Todo)로 쪼개어 단계별로 수행하고 진척도를 표시합니다.
- **예약 작업 관리**: 사용자가 요청한 Cron 일정에 따라 백그라운드 자동화 작업을 등록합니다.

---

## ⚙️ 어시스턴트별 도구 활성화 관리

모든 도구를 켜두면 에이전트가 읽어야 하는 도구 설명이 많아져 모델의 토큰 비용이 늘어납니다.

1. 사이드바에서 **Assistants**를 클릭합니다.
2. 맞춤 설정할 어시스턴트의 **Edit(편집) → Tools 탭**으로 이동합니다.
3. 코딩용 어시스턴트라면 `workspace` 위주로, 리서치용이라면 `browser`를 선택적으로 켜서 최적화할 수 있습니다.

## 📖 기술 참조: 내장 도구 전체 목록 (`{server}__{tool}`)

파워 유저 및 프롬프트 작성을 위한 주요 내장 도구의 정확한 식별자 목록입니다:

| 서버 그룹            | 도구 식별자                           | 설명                                    | 기본 활성            |
| -------------------- | ------------------------------------- | --------------------------------------- | -------------------- |
| **`workspace`**      | `workspace__readFile`                 | 파일 범위 읽기                          | Core (기본)          |
|                      | `workspace__writeFile`                | 새 파일 생성 또는 덮어쓰기              | Core (기본)          |
|                      | `workspace__strReplace`               | 파일 내 문자열 정밀 치환                | Core (기본)          |
|                      | `workspace__listDirectory`            | 디렉토리 파일 목록 조회                 | Core (기본)          |
|                      | `workspace__runShell`                 | 터미널 셸 명령어 실행 (비동기 지원)     | Core (기본)          |
| **`browser`**        | `browser__navigateToUrl`              | 대상 웹페이지 URL 이동 및 로딩          | Optional (선택)      |
|                      | `browser__takeScreenshot`             | 웹 화면 PNG 스크린샷 캡처               | Optional (선택)      |
|                      | `browser__getPageContent`             | 웹페이지 텍스트 및 DOM 구조 추출        | Optional (선택)      |
|                      | `browser__clickElement`               | 웹페이지 요소 클릭                      | Optional (선택)      |
| **`desktop`**        | `desktop__computerControl`            | 마우스 클릭/이동, 키보드 타이핑 OS 제어 | Optional (승인 필요) |
| **`media`**          | `media__captureScreen`                | 데스크톱 모니터 전체/영역 캡처          | Optional (승인 필요) |
|                      | `media__seeContent`                   | 이미지 분석                             | Optional (선택)      |
| **`planning`**       | `planning__createGoal`                | 다단계 목표 수립 및 Todo 관리           | Optional (선택)      |
|                      | `planning__updateGoal`                | 목표 진행 상태 갱신                     | Optional (선택)      |
| **`scheduled_task`** | `scheduled_task__createScheduledTask` | 백그라운드 Cron 예약 작업 등록          | Core (기본)          |
|                      | `scheduled_task__listScheduledTasks`  | 등록된 예약 작업 목록 조회              | Core (기본)          |

## 🧩 외부 도구가 더 필요한가요?

기본 내장 도구 외에 외부 서비스(GitHub, Slack, 데이터베이스 등)와 연결하고 싶다면:

- [Extensions 가이드](extensions.md)를 참고하여 검증된 프리셋을 원클릭으로 추가하거나 자체 커스텀 MCP 서버를 연결할 수 있습니다.
