# 시나리오: 파일 관리 & 변환 자동화

에이전트에게 파일을 지정하면 변환, 요약, 정리, 추출 등을 자동으로 처리하는 워크플로우입니다. 문서 포맷 변환, 데이터 추출, 파일 정리 등 일상적인 파일 작업을 효율적으로 처리합니다.

---

## 🎯 이 시나리오의 목표

- 복잡한 파일 변환 작업을 자연어로 명령
- 대용량 파일의 핵심 내용만 빠르게 요약
- 여러 파일을 체계적으로 정리 및 분류

---

## 📋 단계별 가이드

### 단계 1: 파일 지정

에이전트에게 처리할 파일을 지정합니다. 상대 경로 또는 파일명으로 지정할 수 있습니다.

**파일 경로 지정 예시:**

```
"./documents/report.pdf" 내용을 요약해줘
```

**폴더 전체 지정 예시:**

```
"./downloads/" 폴더에 있는 모든 PDF 파일을 찾아서
각각 한 문장으로 요약해줘.
```

**업로드된 파일 접근:**

에이전트 세션에 파일을 첨부하면 상대 경로로 접근합니다:

```
"./uploads/contract-2026.pdf"에서 계약 조건만 추출해줘.
```

### 단계 2: 작업 지시

파일 처리 방법을 자연어로 지시합니다.

**요약 요청:**

```
"./documents/annual-report-2025.pdf" 파일의 내용을 요약해줘.
다음 항목을 포함해줘:
- 주요 성과
- 재무 현황
- 향후 계획
```

**변환 요청:**

```
"./data/sales-2026.xlsx" 데이터를 마크다운 테이블로 변환해줘.
월별 매출, 순이익, 성장률을 표로 정리해줘.
```

**추출 요청:**

```
"./documents/meeting-notes.docx"에서 액션 아이템만 추출해줘.
담당자와 마감일만 표로 정리해줘.
```

### 단계 3: 결과 확인

에이전트가 처리한 결과를 확인합니다.

**典型 결과 형식:**

```markdown
## 📄 파일 요약: annual-report-2025.pdf

### 주요 성과

- 매출 15% 증가 (전년대비)
- 신규 고객 2,340명 획득
- 3개 신제품 출시

### 재무 현황

| 항목     | 2025 | 2024 | 변화 |
| -------- | ---- | ---- | ---- |
| 매출     | 45억 | 39억 | +15% |
| 영업이익 | 8억  | 6억  | +33% |

### 향후 계획

- 해외 시장 진출 (동남아 1호점)
- R&D 투자 확대 (매출의 5%)
```

### 단계 4: 추가 처리 요청

결과를 바탕으로 추가 작업을 요청합니다.

**수정 요청:**

```
요약이 너무 짧아. 재무 현황 부분을 더 자세히 써줘.
-quarterly 기준으로 분할해서 표로 만들어줘.
```

**저장 요청:**

```
이 결과를 "./summaries/annual-report-2025-summary.md"로 저장해줘.
```

**여러 파일 비교:**

```
"./data/Q1.xlsx", "./data/Q2.xlsx", "./data/Q3.xlsx"를 비교해서
분기별 추이를 분석해줘.
```

## 💡 예시 프롬프트 모음

| 용도             | 프롬프트                                                                           |
| ---------------- | ---------------------------------------------------------------------------------- |
| PDF 요약         | `"./doc/report.pdf 내용을 한 페이지로 요약해줘"`                                   |
| Excel → Markdown | `"./data/sales.xlsx를 마크다운 테이블로 변환해줘"`                                 |
| 문서 추출        | `"./doc/contract.pdf에서 날짜와 금액만 추출해줘"`                                  |
| 파일 이름 변경   | `"./images/ 폴더 이미지 파일들을 'photo-001', 'photo-002'로 이름 변경해줘"`        |
| 폴더 정리        | `"./downloads/를 확장자별로 폴더 만들어서 정리해줘"`                               |
| 텍스트 추출      | `"./doc/scanned.pdf에서 텍스트만 추출해줘"`                                        |
| CSV 변환         | `"./data/raw.txt를 CSV 형식으로 변환해줘"`                                         |
| 파일 병합        | `"./reports/2026-Q1.md", "./reports/2026-Q2.md"를 합쳐서 Q1-Q2 보고서를 만들어줘"` |
| 메타데이터 추출  | `"./doc/presentation.pptx에서 슬라이드 제목만 추출해줘"`                           |

## 📁 지원 파일 형식

에이전트가 기본적으로 처리할 수 있는 파일 형식:

| 형식          | 지원 작업                           |
| ------------- | ----------------------------------- |
| PDF           | 요약, 텍스트 추출, 테이블 인식      |
| DOCX          | 요약, 형식 변환, 텍스트 추출        |
| XLSX/CSV      | 테이블 변환, 데이터 분석, 차트 생성 |
| PPTX          | 슬라이드 요약, 텍스트 추출          |
| Markdown      | 요약, 변환, 병합                    |
| 텍스트 (.txt) | 요약, 분석, 변환                    |
| 이미지        | OCR 텍스트 추출                     |
| JSON          | 데이터 분석, 테이블 변환            |

> **💡 참고:** 일부 파일 형식은 추가 설정이 필요할 수 있습니다.

## ⚙️ 설정 팁

### 파일 작업 전용 에이전트 만들기

1. `/assistants`에서 새 에이전트 생성
2. 시스템 프롬프트:
   ```
   당신은 파일 관리 전문가입니다.
   주어진 파일을 빠르게 분석하고 요약, 변환, 정리를 수행합니다.
   파일 구조를 명확하게 표시하고, 결과를 정리된 형식으로 제공합니다.
   ```
3. 파일 접근 권한 있는 도구 활성화

### 대용량 파일 처리

대용량 파일 처리 시:

```
"./large-document.pdf"를 처리해줘.
단, 한 번에 모든 내용을 처리하지 말고
섹션별로 나누어서 단계별로 요약해줘.
```

### 자동화 연결

정기적인 파일 처리 작업을 예약하려면:

1. `/scheduled-tasks`에서 새 작업 생성
2. "매주 월요일 /reports/ 폴더의 PDF 파일들을 요약해줘"
3. 에이전트와 반복 주기 설정
