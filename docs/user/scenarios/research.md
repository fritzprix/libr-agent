# 시나리오: 심층 리서치 & 리포트 작성

에이전트에게 연구 주제를 지정하면 웹 검색, 자료 수집, 분석을 거쳐 구조화된 리포트를 작성하는 워크플로우입니다. 시장 조사, 학술 조사, 경쟁사 분석 등 다양한 용도로 활용합니다.

---

## 🎯 이 시나리오의 목표

- 복잡한 주제를 체계적으로 조사하고 종합된 리포트 받기
- 여러 출처의 정보를 비교·분석하여 신뢰할 수 있는 결론 도출
- 참고 자료와 함께 구조화된 리포트 생성

---

## 📋 단계별 가이드

### 단계 1: 연구 주제 지정

에이전트에게 조사할 주제를 명확히 지정합니다.

**기본 요청:**

```
"AI 에이전트 플랫폼 시장의 현재 동향에 대해 조사해줘"
```

**구체적인 요청:**

```
"2026년 기준 자율주행 기술의 상용화 수준을 조사해줘.
주요 기업별 현황, 기술적 과제, 예상 상용화 시기를 포함해줘."
```

### 단계 2: 리서치 범위 설정 (선택)

조사 범위, 깊이, 형식을 지정할 수 있습니다.

**범위 지정 예시:**

```
"이 주제에 대해 조사해줘:
- 최근 1년 이내 자료 위주로
- 영어와 한국어 자료 모두 포함
- 최소 5개 이상의 출처 인용
- 표와 차트로 데이터 비교"
```

**깊이 지정 예시:**

```
"이 주제를 3단계 깊이가로 조사해줘:
1. 개요 (1페이지)
2. 주요 이슈 상세 분석
3. 전망 및 시사점"
```

**형식 지정 예시:**

```
"조사 결과를 다음 형식으로 정리해줘:
- 실행 요약 (Executive Summary)
- 현황 분석
- 경쟁사 비교표
- 향후 전망
- 참고 자료"
```

### 단계 3: 조사 진행 중 확인

에이전트가 조사 중인 결과를 중간에 확인할 수 있습니다.

**중간 확인 요청:**

```
"지금까지 조사한 내용을 간략히 요약해줘.
어떤 자료가 가장 신뢰할 만한지 알려줘."
```

**추가 조사 요청:**

```
"최근 2주 안에 나온 최신 뉴스로도 검색해줘.
구체적인 수치와 통계 자료가 있으면 더 찾아봐."
```

### 단계 4: 결과 확인 및 보정

에이전트가 완성한 리포트를 확인하고 추가 요청을 보냅니다.

**결과 확인 예시:**

```
"리포트 잘 봤어. 다음 부분을 보강해줘:
1. 한국 기업 현황 부분이 너무 간단해. 삼성, 네이버, 카카오 현황 추가
2. 통계 자료를 가능한 최신 것으로 교체
3. 결론 부분에 실제 적용 가능한 인사이트 추가"
```

**최종 요청:**

```
"마무리했어. 이 리포트를 Markdown 파일로 저장해줘.
파일명은 '2026-08-08_AIAgentMarketAnalysis.md'로 해줘."
```

## 💡 예시 프롬프트 모음

| 용도        | 프롬프트                                                 |
| ----------- | -------------------------------------------------------- |
| 기본 리서치 | `"{주제}에 대해 심층 조사해줘"`                          |
| 시장 조사   | `"'{시장}' 시장 규모, 성장률, 주요 플레이어를 조사해줘"` |
| 경쟁사 분석 | `"{회사A}와 {회사B}의 {제품}을 비교 분석해줘"`           |
| 기술 동향   | `"{기술}의 최근 6개월 기술 동향을 조사해줘"`             |
| 뉴스 요약   | `"{주제} 관련 최근 뉴스를 요약해줘. 출처 포함"`          |
| 보고서 생성 | `"조사 결과를 보고서 형식으로 정리해줘. 실행 요약 포함"` |
| 인용 자료   | `"사용한 모든 출처를 링크와 함께 목록으로 정리해줘"`     |
| 비교표 생성 | `"{항목A}와 {항목B}를 표로 비교해줘"`                    |

## 📊 리포트 예시 구조

에이전트가 생성하는 리포트의典型 구조:

```markdown
# [제목]

## 📋 실행 요약

한 문단으로 핵심 내용을 요약

## 📊 현황 분석

- 주요 데이터와 통계
- 시장 규모, 성장률, 트렌드

## 🔍 심층 분석

- 세부 주제별 분석
- 비교표 및 인사이트

## 🏢 주요 기업/기관

- 개요
- 현황
- 전략 및 방향성

## 🔮 향후 전망

- 예상 트렌드
- 기회와 위협
- 시사점

## 📚 참고 자료

1. [출처명](링크) - 인용 내용
2. ...
```

## ⚙️ 설정 팁

### 리서치 전용 에이전트 만들기

1. `/assistants`에서 새 에이전트 생성
2. 시스템 프롬프트:
   ```
   당신은 전문 리서치 어시스턴트입니다.
   사실에 기반한 정확한 정보를 제공하며, 출처를 반드시 명시합니다.
   추측이나 확인되지 않은 정보는 명시적으로 알려줍니다.
   ```
3. 브라우징 도구 활성화 (웹 검색용)

### 신뢰성 확보 방법

- 에이전트에게 "출처를 반드시 명시해줘"라고 반복 요청
- 서로 다른 출처의 정보를 비교하도록 지시
- "이 정보가 최신인지 확인해줘"라고 요청
- 불확실한 정보는 "확인 필요"로 표시하도록 설정
