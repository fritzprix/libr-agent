# 시나리오: 웹 검색 & 정보 수집

에이전트에게 웹 검색이나 웹사이트 주소를 제공하면 실시간 정보를 수집, 분석, 요약하는 워크플로우입니다. 뉴스 조사, 제품 비교, 트렌드 분석 등 다양한 용도로 활용합니다.

---

## 🎯 이 시나리오의 목표

- 실시간 웹 정보를 에이전트가 자동으로 수집하고 요약
- 여러 웹사이트의 정보를 비교 분석
- 반복적인 웹 조사를 자동화

---

## 📋 단계별 가이드

### 단계 1: 검색어 또는 URL 제공

에이전트에게 검색할 주제나 확인할 웹사이트 주소를 지정합니다.

**검색어 기반:**

```
"2026년 AI 에이전트 플랫폼 시장 동향을 조사해줘"
```

**URL 직접 제공:**

```
"https://techcrunch.com/category/artificial-intelligence/" 이 페이지의 최신 기사만 요약해줘.
```

**여러 URL 비교:**

```
이 세 사이트를 비교 분석해줘:
- https://example.com/product-a
- https://example.com/product-b
- https://example.com/product-c
```

### 단계 2: 브라우징 명령

에이전트가 브라우저로 웹사이트에 접속하여 정보를 수집합니다.

**기본 브라우징:**

```
"https://news.ycombinator.com/" 에 접속해서 AI 관련 최신 글 5개 요약해줘.
```

**특정 정보 추출:**

```
"https://github.com/trending" 에서 Python 언어별 프로젝트 Top 10을 추출해줘.
```

**페이지 내 검색:**

```
"https://docs.python.org/3/" 에서 "async" 관련 문서 찾아서 요약해줘.
```

### 단계 3: 결과 확인

에이전트가 수집한 웹 정보를 구조화하여 반환합니다.

**典型 결과 형식:**

```markdown
## 📰 AI 에이전트 플랫폼 시장 동향

### 주요 기사

1. **[플랫폼 A, 시드 투자 유치]**
   - 출처: TechCrunch (2026-08-05)
   - 내용: 시리즈 A 라운드에서 500만 달러 투자 유치...
   - 링크: https://techcrunch.com/...

2. **[플랫폼 B, 기업용 솔루션 출시]**
   - 출처: The Verge (2026-08-03)
   - 내용: Enterprise AI 에이전트 플랫폼 출시...
   - 링크: https://theverge.com/...

### 시장 분석

- 현재 주요 플레이어: A사, B사, C사
- 시장 규모: 2026년 기준 약 $XX억
- 성장률: 전년 대비 XX% 증가
- 주목할 트렌드:
  - 엔터프라이즈 시장 급성장
  - 오픈소스 플랫폼 경쟁 심화
  - 멀티모달 에이전트 채택 증가
```

### 단계 4: 심화 분석 요청

수집한 정보를 바탕으로 추가 분석을 요청합니다.

**비교 분석:**

```
A사와 B사의 제품을 표로 비교해줘. 가격, 기능, 지원 모델을 포함해줘.
```

**최신 정보 추가:**

```
"오늘 하루 사이에 나온 관련 뉴스가 더 있다면 찾아줘."
```

**출처 검증:**

```
"이 정보들의 출처 신뢰도를 평가해줘.
어떤 출처가 가장 신뢰할 만한지 알려줘."
```

**저장 요청:**

```
이 조사 결과를 "./research/ai-platform-trends-2026.md"로 저장해줘."
```

## 💡 예시 프롬프트 모음

| 용도          | 프롬프트                                                             |
| ------------- | -------------------------------------------------------------------- |
| 뉴스 검색     | `"최근 1주일 간 '{주제}' 관련 뉴스 10개 요약해줘"`                   |
| 웹사이트 요약 | `"https://example.com 이 페이지의 핵심 내용 요약해줘"`               |
| 제품 비교     | `"https://a.com/1, https://b.com/2 이 두 제품 비교해줘"`             |
| 트렌드 조사   | `"'{기술}' 관련 최근 3개월 트렌드를 조사해줘"`                       |
| 가격 비교     | `"https://a.com, https://b.com, https://c.com 가격 비교표 만들어줘"` |
| 리뷰 수집     | `"'{제품}' 리뷰를 3개 사이트에서 수집해서 긍정/부정 비율 분석해줘"`  |
| 문서 검색     | `"https://docs.example.com 에서 '{키워드}' 관련 문서 찾아줘"`        |
| 블로그 정리   | `"https://blog.example.com 최근 5개 포스트 요약해줘"`                |
| 실시간 정보   | `"현재 '{이벤트}' 관련 최신 상황을 검색해줘"`                        |

## 🌐 브라우징 기능 설정

### 브라우징 활성화

에이전트가 웹을 브라우징하려면 브라우저 도구가 활성화되어 있어야 합니다.

**브라우저 도구 확인:**

1. `/assistants`에서 에이전트 설정 확인
2. "Browser" 또는 "웹 브라우징" 도구가 활성화되어 있는지 확인
3. 활성화되어 있지 않으면 설정에서 토클

### 에이전트 설정 예시

웹 브라우징에 특화된 에이전트:

```
시스템 프롬프트:
당신은 웹 조사 전문가입니다.
실시간 웹 정보를 수집하고, 신뢰할 수 있는 출처를 확인하며,
구조화된 리포트를 작성합니다.
```

## ⚠️ 주의사항

### 웹사이트 접근 제한

- 일부 웹사이트는 자동화된 접근을 차단할 수 있습니다
- 접근 불가 시 에러 메시지가 표시됩니다
- 이 경우 수동으로 링크를 복사해서 제공하면 에이전트가 내용을 요약합니다

### 정보 신뢰성

- 웹에서 수집한 정보는 실시간이지만 검증이 필요합니다
- 에이전트가 출처를 명시하므로 반드시 원문 링크 확인
- 중요한 결정을 위해 여러 출처 교차 검증 권장

### 브라우징 한도

- 한 세션에서过多的인 브라우징은 제한될 수 있습니다
- 대량 수집이 필요한 경우 여러 세션에 나누거나 예약 작업 활용
