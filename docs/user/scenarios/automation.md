# 시나리오: 예약 자동화 & 정기 작업

에이전트에게 반복 작업을 예약하면 지정한 시간이나 주기에 따라 자동으로 작업을 수행합니다. 매일 아침 뉴스 요약, 주간 리포트 생성, 정기 파일 정리 등 일정을 정해두면 에이전트가 알아서 처리합니다.

---

## 🎯 이 시나리오의 목표

- 매일·매주 반복되는 작업을 한 번 설정하면 자동으로 처리
- 수동 확인 없이도 정기적으로 리포트, 요약, 정리 작업 수행
- 여러 에이전트를 활용하여 분산된 자동화 워크플로우 구성

---

## 📋 단계별 가이드

### 단계 1: 자동화할 작업 결정

매일, 매주, 매월 등 반복할 작업을 명확히 정의합니다.

**일일 작업 예시:**

```
- 매일 아침 9시: AI 관련 최신 뉴스 10개 요약
- 매일 오후 6시: 오늘 받은 이메일 요약
- 매일 자정: 다운로드 폴더 정리
```

**주간 작업 예시:**

```
- 매주 월요일 10시: 주간 프로젝트 리포트 생성
- 매주 금요일 17시: 이번 주 회의록 정리
```

**월간 작업 예시:**

```
- 매월 1일: 월간 매출 리포트 생성
- 매월 마지막 금요일: 코드 리뷰 일정 정리
```

### 단계 2: 에이전트에게 작업 지시 및 예약

에이전트에게 작업 내용과 예약 주기를 함께 전달합니다.

**기본 예약 요청:**

```
매일 오전 9시에 다음 작업을 예약해줘:
- AI 관련 최신 뉴스 10개 검색
- 각 기사 한 줄 요약 생성
- 참고 링크 포함
- 결과를 'daily-reports/ai-news-{날짜}.md'로 저장
```

**복합 작업 예약:**

```
매주 월요일 오전 10시에 다음 작업을 진행해줘:
1. 지난 주 Git 커밋 로그 확인
2. 주요 변경 사항 요약
3. 팀원별 기여도 정리
4. 주간 리포트를 'weekly-reports/weekly-{날짜}.md'로 저장
```

**여러 에이전트 활용:**

```
다음 자동화를 설정해줘:
- 매일 오전 8시: '리서치 에이전트'에게 AI 뉴스 리포트 요청
- 매일 오전 9시: '번역 에이전트'에게 리포트를 한국어로 번역 요청
- 매일 오전 10시: 완성된 리포트를 'reports/ko/' 폴더에 저장
```

### 단계 3: 예약 확인 및 수정

예약된 작업을 확인하고 필요시 수정할 수 있습니다.

**예약 목록 확인:**

```
지금 예약된 자동화 작업들을 모두 알려줘.
각 작업의 실행 시간과 내용을 요약해줘.
```

**예약 수정:**

```
매일 오전 9시 AI 뉴스 리포트 시간을
오후 2시로 변경해줘.
```

**예약 중지/재개:**

```
매주 월요일 주간 리포트 생성 예약을 잠시 중지해줘.
(필요할 때 다시 활성화할 수 있어?)
```

### 단계 4: 결과 확인

에이전트가 실행한 자동화 결과를 확인합니다.

**결과 확인 요청:**

```
최근 1주일 간 생성된 자동화 리포트들을 확인해줘.
어떤 리포트들이 생성되었는지 요약해줘.
```

**문제 보고 확인:**

```
자동화 작업 중 실패한 것이 있었는지 확인해줘.
실패한 작업이 있다면 원인과 해결 방법을 알려줘.
```

## ⏰ 예약 유형별 가이드

### 매일 반복 (Daily)

**적합한 작업:**
- 뉴스 요약, 일일 리포트
- 파일 정리, 백업
- 메일/알림 확인

**예시:**

```
매일 오전 9시 (한국 시간)에 다음을 실행해줘:
1. AI 관련 뉴스 10개 검색
2. 각 기사 한 줄 요약
3. 결과를 daily-reports/{날짜}.md에 저장
```

### 매주 반복 (Weekly)

**적합한 작업:**
- 주간 리포트, 커밋 분석
- 회의록 정리
- 데이터 분석 리포트

**예시:**

```
매주 월요일 오전 10시에:
1. 지난 주 Git 커밋 확인
2. 주요 변경 사항 요약
3. 주간 리포트 생성 (weekly-reports/에 저장)
```

### 매월 반복 (Monthly)

**적합한 작업:**
- 월간 매출/성과 리포트
- 코드 품질 리포트
- 시스템 상태 점검

**예시:**

```
매월 1일 오전 10시에:
1. 지난 달 Git 통계 수집
2. 월간 리포트 생성
3. 팀원별 기여도 분석 포함
```

### 특정 시간 간격 (Interval)

**적합한 작업:**
- 시스템 모니터링
- 로그 점검
- 데이터 동기화

**예시:**

```
매시간 0분에 다음을 확인해줘:
- 서버 응답 시간
- 에러 로그 증가 여부
-异常이 감지되면 알림
```

## ⚙️ 설정 팁

### 자동화 에이전트 만들기

자동화 작업에 전용 에이전트를 사용하는 것이 좋습니다.

1. `/assistants`에서 새 에이전트 생성
2. 이름: "자동화 에이전트" 또는 "Scheduled Agent"
3. 시스템 프롬프트:
   ```
   당신은 자동화된 작업을 수행하는 에이전트입니다.
   예약된 작업을 정확하고 빠르게 처리합니다.
   작업 결과는 명확하게 기록하고, 실패 시 원인을 보고합니다.
   ```
4. 필요한 도구만 활성화 (필요한 도구는 최소한으로)

### 실패 대응 설정

자동화 작업이 실패했을 때의 행동을 정의하세요:

```
자동화 작업 실행 시:
- 실패하면 결과를 'errors/' 폴더에 로그로 저장
- 매일 아침 실패한 작업 목록 확인
- 중요한 작업 실패 시 알림
```

### 리소스 관리

많은 자동화 작업이 동시에 실행되지 않도록 주의하세요:

```
자동화 작업 설정 시:
- 서로 다른 시간대에 배치
- CPU/메모리 집약적 작업은错峰 (피크 시간대 피해)
- 동시 실행 작업 수는 최대 3개 이하로 제한
```
