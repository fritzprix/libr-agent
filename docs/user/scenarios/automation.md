# 시나리오: 예약 자동화 & 정기 작업

에이전트에게 반복 작업을 예약하면 지정한 시간이나 주기에 따라 자동으로 작업을 수행합니다. 매일 아침 뉴스 요약, 주간 리포트 생성, 정기 파일 정리 등 일정을 정해두면 에이전트가 알아서 처리합니다.

---

## 🎯 이 시나리오의 목표

- 매일·매주 반복되는 작업을 한 번 설정하면 자동으로 처리
- 수동 확인 없이도 정기적으로 리포트, 요약, 정리 작업 수행
- 여러 에이전트를 활용하여 분산된 자동화 워크플로우 구성

---

## 📋 단계별 가이드

### 단계 1: 자동화할 작업 정의

매일, 매주, 매월 등 반복할 작업을 명확히 정의합니다. **일상 예시부터** 시작하고, Git·서버 점검은 필요할 때만 추가하세요.

**일상 — 일일 작업 예시:**

```
- 매일 아침 9시: AI 관련 최신 뉴스 10개 요약
- 매일 오후 6시: 오늘 받은 이메일 요약
- 매일 자정: 다운로드 폴더 정리
```

**일상 — 주간 작업 예시:**

```
- 매주 월요일 10시: 주간 프로젝트 리포트 생성
- 매주 금요일 17시: 이번 주 회의록 정리
```

**일상 — 월간 작업 예시:**

```
- 매월 1일: 월간 매출 리포트 생성
- 매월 마지막 금요일: 다음 달 할 일 목록 정리
```

**선택 (개발자):** Git 커밋 요약, 서버 응답 점검 등은 아래 예시에서 필요 시만 사용하세요.

### 단계 2: 예약하기 (Scheduled Tasks UI 권장)

가장 쉬운 방법은 사이드바 **Scheduled Tasks**에서 새 작업을 만들고 스케줄·메시지를 넣는 것입니다. 채팅으로도 요청할 수 있습니다.

**기본 예약 요청 (일상):**

```
매일 오전 9시에 다음 작업을 예약해줘:
- AI 관련 최신 뉴스 10개 검색
- 각 기사 한 줄 요약 생성
- 참고 링크 포함
- 결과를 'daily-reports/ai-news-{날짜}.md'로 저장
```

**복합 작업 예약 (일상):**

```
매주 금요일 오후 5시에 다음 작업을 진행해줘:
1. ./downloads/ 폴더에서 이번 주 받은 PDF 찾기
2. 각 파일을 한 줄로 요약
3. 요약을 'weekly-reports/files-{날짜}.md'로 저장
```

**선택 (개발자) — Git 주간 요약:**

```
매주 월요일 오전 10시에 지난 주 Git 커밋을 요약해
'weekly-reports/weekly-{날짜}.md'로 저장해줘.
```

### 단계 3: 예약 확인 및 수정

예약된 작업을 확인하고 필요시 수정할 수 있습니다. 사이드바 **Scheduled Tasks** 목록에서도 편집·중지할 수 있습니다.

**예약 목록 확인:**

```
지금 예약된 자동화 작업들을 모두 알려줘.
각 작업의 실행 시간과 내용을 요약해줘.
```

**예약 수정:**

```
매일 오전 9시 AI 뉴스 리포트 시간을
오후 2시로 변경해줘.
```

**예약 중지/재개:**

```
매주 금요일 파일 요약 예약을 잠시 중지해줘.
(필요할 때 다시 활성화할 수 있어?)
```

### 단계 4: 결과 확인

에이전트가 실행한 자동화 결과를 확인합니다.

**결과 확인 요청:**

```
최근 1주일 간 생성된 자동화 리포트들을 확인해줘.
어떤 리포트들이 생성되었는지 요약해줘.
```

**문제 보고 확인:**

```
자동화 작업 중 실패한 것이 있었는지 확인해줘.
실패한 작업이 있다면 원인과 해결 방법을 알려줘.
```

## ⏰ 예약 유형별 가이드

### 매일 반복 (Daily)

**적합한 작업:**

- 뉴스 요약, 일일 리포트
- 파일 정리, 백업
- 메일/알림 확인

**예시:**

```
매일 오전 9시 (한국 시간)에 다음을 실행해줘:
1. AI 관련 뉴스 10개 검색
2. 각 기사 한 줄 요약
3. 결과를 daily-reports/{날짜}.md에 저장
```

### 매주 반복 (Weekly)

**적합한 작업:**

- 주간 리포트, 회의록 정리
- 파일·폴더 정리
- 데이터 분석 리포트

**예시 (일상):**

```
매주 금요일 오후 5시에:
1. ./downloads/ 정리
2. 새 PDF 한 줄 요약
3. weekly-reports/에 저장
```

**선택 (개발자):**

```
매주 월요일 오전 10시에:
1. 지난 주 Git 커밋 확인
2. 주요 변경 사항 요약
3. 주간 리포트 생성 (weekly-reports/에 저장)
```

### 매월 반복 (Monthly)

**적합한 작업:**

- 월간 매출/성과 리포트
- 할 일·일정 정리

**예시:**

```
매월 1일 오전 10시에:
1. 지난 달 메모·리포트 폴더 훑기
2. 월간 요약 리포트 생성
```

### 특정 시간 간격 (Interval) — 선택

서버 핑·로그 점검 같은 인프라 작업은 선택 사항입니다.

```
매시간 0분에 다음을 확인해줘:
- 서버 응답 시간
- 에러 로그 증가 여부
- 이상이 감지되면 알림
```

## ⚙️ 설정 팁

### 자동화 에이전트 만들기

자동화 작업에 전용 에이전트를 사용하는 것이 좋습니다.

1. 사이드바 **Assistants**에서 새 에이전트 생성
2. 이름: "자동화 에이전트" 또는 "Scheduled Agent"
3. 시스템 프롬프트:
   ```
   당신은 자동화된 작업을 수행하는 에이전트입니다.
   예약된 작업을 정확하고 빠르게 처리합니다.
   작업 결과는 명확하게 기록하고, 실패 시 원인을 보고합니다.
   ```
4. 필요한 도구만 활성화 (필요한 도구는 최소한으로)

### 실패 대응 설정

자동화 작업이 실패했을 때의 행동을 정의하세요:

```
자동화 작업 실행 시:
- 실패하면 결과를 'errors/' 폴더에 로그로 저장
- 매일 아침 실패한 작업 목록 확인
- 중요한 작업 실패 시 알림
```

### 리소스 관리

많은 자동화 작업이 동시에 실행되지 않도록 주의하세요:

```
자동화 작업 설정 시:
- 서로 다른 시간대에 배치
- CPU/메모리를 많이 쓰는 작업은 피크 시간대를 피함
- 동시 실행 작업 수는 최대 3개 이하로 제한
```

```

- 이름
- 실행 주기

- 최근 실패 여부
- 다음 실행 예정 시간
```
