## 1. 투자자 데모의 핵심 목표

마케팅 데모가 **"사용자가 왜 써야 하는가"**를, 기술 데모가 **"어떻게 설계되었는가"**를 증명한다면, 투자자 데모는 **"왜 이 팀에 $2M을 던져야 하는가"**를 증명합니다.

### 3개의 질문을 답해야 합니다

```
Q1: "이 시장이 진짜로 큰가?"          → TAM $50.3B, CAGR 45.8% 시각화
Q2: "단위 경제가 정말 작동하는가?"    → LTV:CAC 6.8:1, NDR 118%, Churn <2%
Q3: "$2M으로 Series A에 도달 가능한가?" → 18개월 런웨이, Break-even Year 2 Q4
```

### 데모 원칙 (투자자용)

| 원칙 | 내용 |
|------|------|
| **Numbers first, features second** | 기능 설명보다 성장 곡선, 단위 경제, 펀딩 계획이 우선 |
| **Proof, not promises** | "할 계획"이 아닌 "이미 구축된 상태"를 보여줌 (170+ 도구, 13 에이전트) |
| **Competitive Moat** | Cursor/Copilot과 달리 로컬 우선 + OSS + 온프레미스의 유일 위치 증명 |
| **Capital Efficiency** | Tauri/Rust의 경량성으로 인프라 비용 30% 절감 → 높은 마진 |
| **Clear Path to Exit** | Year 5 ARR $1.23B → Exit $864M+ → Seed $2M 기준 432x 리턴 가능성 |

**시연 동작:**
1. **MRR 성장 애니메이션** — Year 1 $321K → Year 3 $9.6M → Year 5 $102M
2. **단위 경제 대시보드** 실시간 표시:
   - Pro: LTV $330 / CAC $45 = **7.3:1**
   - Teams: LTV $3,600 / CAC $400 = **9.0:1**
   - Enterprise: LTV $42,000 / CAC $2,500 = **16.8:1**
3. **NDR 시각화** — 기존 고객 수익이 매년 8-18% 증가 (업셀 + 크로스셀)
4. **Churn Rate** — Pro 3%, Teams 1.5%, Enterprise 0.5% → 평균 <2%

**핵심 메시지**: "단위 경제가 정말 작동합니다. LTV:CAC 6.8:1은 SaaS 벤치마크(3:1)의 2.3배, NDR 118%는 구독 기반 SaaS에서 우수한 수준입니다. Churn이 2% 미만이라는 것은 제품이 '그만두고 싶은' 것이 아니라 '더 써야 하는' 상태라는 뜻입니다."

**투자자 반응 목표**: "단위 경제가 이렇게 좋으면... 더 투자하고 싶다."
