# Refactoring Plan: Assistant Manager 검색 및 페이지네이션 구현

## 작업의 목적

`assistant-manager` MCP 서버에 **BM25 기반 검색 기능(`search_assistant`)**과 **목록 조회 페이지네이션(`list_assistants`)**을 추가하여, 사용자가 원하는 Assistant를 효율적으로 찾고 관리할 수 있도록 개선합니다.

## 현재의 상태 / 문제점

1. **검색 기능 부재**: 현재 `assistant-manager`는 단순 CRUD만 지원하며, 특정 Assistant를 찾기 위해서는 전체 목록을 조회해야 합니다.
2. **대량 데이터 조회 비효율**: `list_assistants`가 필터링이나 페이징 없이 모든 Assistant를 반환하므로, Assistant 수가 늘어날 경우 성능 저하 및 응답 크기 문제가 발생할 수 있습니다.
3. **BM25 활용 미비**: 프로젝트 내에 이미 구현된 `src/lib/search/bm25.ts`가 존재하지만, 이를 Assistant 검색에 활용하고 있지 않습니다.

## 관련 코드의 구조 및 동작 방식 Summary (Bird's Eye View)

- **`src/lib/web-mcp/modules/assistant-manager/server.ts`**: `assistant_manager` MCP 서버의 진입점으로, `callTool` 메서드에서 각 도구의 요청을 처리합니다. 현재 `AssistantService`를 통해 데이터를 조회합니다.
- **`src/lib/web-mcp/modules/assistant-manager/tools.ts`**: MCP 도구들의 스키마(입력/출력 정의)를 관리합니다.
- **`src/lib/services/assistant-service.ts`**: `Assistant` 모델에 대한 CRUD를 담당하는 서비스 레이어입니다. `dbUtils.getAllAssistants()`를 통해 데이터를 가져옵니다.
- **`src/lib/search/bm25.ts`**: BM25 랭킹 알고리즘과 토크나이저, 인메모리 캐싱(`createBM25Index`)을 제공하는 유틸리티입니다.

## 변경 이후의 상태 / 해결 판정 기준

1. **`search_assistant` 도구 사용 가능**:
   - 사용자가 자연어 쿼리로 Assistant를 검색할 수 있어야 합니다.
   - 검색 결과는 BM25 점수 순으로 정렬되어야 합니다.
   - `name`, `description`, `systemPrompt` 필드가 검색 대상에 포함되어야 합니다.
2. **`list_assistants` 페이지네이션 지원**:
   - `page` (기본값 1), `pageSize` (기본값 20) 파라미터를 받아 해당 범위의 Assistant만 반환해야 합니다.
   - 전체 아이템 수(`total`) 정보를 포함하여 반환해야 합니다.

### 2. `src/lib/services/assistant-service.ts`

`IAssistantService` 인터페이스를 수정하여 페이지네이션을 강제하고, **Stale-While-Revalidate** 전략을 사용하여 검색 인덱스를 관리합니다.

```typescript
import { BM25Index, defaultTokenizer, BM25Doc } from '@/lib/search/bm25';

export interface PaginationParams {
  page: number;
  pageSize: number;
}

export interface PaginatedResult<T> {
  items: T[];
  total: number;
  page: number;
  pageSize: number;
}

export interface IAssistantService {
  getList(params: PaginationParams): Promise<PaginatedResult<Assistant>>;
  getAll(): Promise<Assistant[]>;
  getById(id: string): Promise<Assistant | undefined>;
  save(assistant: Assistant): Promise<Assistant>;
  saveAll(assistants: Assistant[]): Promise<Assistant[]>;
  delete(id: string): Promise<void>;
  search(query: string, limit?: number): Promise<Assistant[]>; // 검색 메서드 추가
}

export class LocalAssistantService implements IAssistantService {
  private searchIndex: BM25Index | null = null;
  private assistantMap: Map<string, Assistant> = new Map();
  private isIndexing = false;

  constructor() {
    // 초기화 시 인덱스 빌드 시작 (await 하지 않음)
    this.refreshIndex();
  }

  private async refreshIndex() {
    if (this.isIndexing) return;
    this.isIndexing = true;
    try {
      const assistants = await dbUtils.getAllAssistants();

      // ID→Assistant Map 캐싱 (검색 성능 최적화)
      this.assistantMap = new Map(assistants.map((a) => [a.id!, a]));

      const docs: BM25Doc[] = assistants.map((a) => ({
        id: a.id,
        tokens: [
          ...defaultTokenizer(a.name),
          ...defaultTokenizer(a.description || ''),
          ...defaultTokenizer(a.systemPrompt),
        ],
      }));

      const newIndex = new BM25Index();
      newIndex.addDocuments(docs);
      this.searchIndex = newIndex; // 인덱스 교체 (Atomic하게 동작)
    } catch (error) {
      logger.error('Failed to refresh search index', error);
    } finally {
      this.isIndexing = false;
    }
  }

  async search(query: string, limit = 10): Promise<Assistant[]> {
    // 인덱스가 없으면 빌드 대기 (첫 실행 시)
    if (!this.searchIndex) {
      await this.refreshIndex();
    }

    if (!this.searchIndex) return []; // 빌드 실패 시 빈 배열

    const queryTokens = defaultTokenizer(query);
    const scores = this.searchIndex.score(queryTokens);

    // Map 캐시를 활용한 고성능 조회
    return Array.from(scores.entries())
      .filter(([_, score]) => score > 0)
      .sort((a, b) => b[1] - a[1])
      .slice(0, limit)
      .map(([id]) => this.assistantMap.get(id)!)
      .filter(Boolean);
  }

  async getList(params: PaginationParams): Promise<PaginatedResult<Assistant>> {
    const all = await dbUtils.getAllAssistants();
    const start = (params.page - 1) * params.pageSize;
    const end = start + params.pageSize;

    return {
      items: all.slice(start, end),
      total: all.length,
      page: params.page,
      pageSize: params.pageSize,
    };
  }

  async getAll(): Promise<Assistant[]> {
    return dbUtils.getAllAssistants();
  }

  async getById(id: string): Promise<Assistant | undefined> {
    return dbService.assistants.read(id);
  }

  async save(assistant: Assistant): Promise<Assistant> {
    await dbService.assistants.upsert(assistant);
    this.refreshIndex(); // 백그라운드 인덱스 갱신 (await 하지 않음)
    return assistant;
  }

  async saveAll(assistants: Assistant[]): Promise<Assistant[]> {
    if (assistants.length === 0) return [];
    await dbService.assistants.upsertMany(assistants);
    this.refreshIndex();
    return assistants;
  }

  async delete(id: string): Promise<void> {
    await dbService.assistants.delete(id);
    this.refreshIndex(); // 백그라운드 인덱스 갱신 (await 하지 않음)
  }
}

export class RemoteAssistantService implements IAssistantService {
  constructor(private baseUrl: string) {}

  async getList(params: PaginationParams): Promise<PaginatedResult<Assistant>> {
    const response = await fetch(
      `${this.baseUrl}/assistants?page=${params.page}&pageSize=${params.pageSize}`,
    );
    if (!response.ok) throw new Error('Failed to fetch assistants');
    return response.json();
  }

  async search(query: string, limit = 10): Promise<Assistant[]> {
    const response = await fetch(
      `${this.baseUrl}/assistants/search?q=${encodeURIComponent(query)}&limit=${limit}`,
    );
    if (!response.ok) throw new Error('Failed to search assistants');
    return response.json();
  }

  async getAll(): Promise<Assistant[]> {
    const response = await fetch(`${this.baseUrl}/assistants`);
    if (!response.ok) throw new Error('Failed to fetch assistants');
    return response.json();
  }

  async getById(id: string): Promise<Assistant | undefined> {
    const response = await fetch(`${this.baseUrl}/assistants/${id}`);
    if (response.status === 404) return undefined;
    if (!response.ok) throw new Error('Failed to fetch assistant');
    return response.json();
  }

  async save(assistant: Assistant): Promise<Assistant> {
    const response = await fetch(`${this.baseUrl}/assistants`, {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify(assistant),
    });
    if (!response.ok) throw new Error('Failed to save assistant');
    return response.json();
  }

  async saveAll(assistants: Assistant[]): Promise<Assistant[]> {
    const saved: Assistant[] = [];
    for (const assistant of assistants) {
      saved.push(await this.save(assistant));
    }
    return saved;
  }

  async delete(id: string): Promise<void> {
    const response = await fetch(`${this.baseUrl}/assistants/${id}`, {
      method: 'DELETE',
    });
    if (!response.ok) throw new Error('Failed to delete assistant');
  }
}

export class AssistantService implements IAssistantService {
  private localService: LocalAssistantService;
  private remoteService: RemoteAssistantService | null = null;

  constructor(agentHubUrl?: string) {
    this.localService = new LocalAssistantService();
    if (agentHubUrl) {
      this.remoteService = new RemoteAssistantService(agentHubUrl);
    }
  }

  // Exclusive Mode: agentHubUrl이 있으면 Remote만 사용, 없으면 Local만 사용

  async getList(params: PaginationParams): Promise<PaginatedResult<Assistant>> {
    if (this.remoteService) {
      return await this.remoteService.getList(params);
    }
    return this.localService.getList(params);
  }

  async search(query: string, limit = 10): Promise<Assistant[]> {
    if (this.remoteService) {
      return await this.remoteService.search(query, limit);
    }
    return this.localService.search(query, limit);
  }

  async getAll(): Promise<Assistant[]> {
    if (this.remoteService) {
      return await this.remoteService.getAll();
    }
    return this.localService.getAll();
  }

  async getById(id: string): Promise<Assistant | undefined> {
    if (this.remoteService) {
      return await this.remoteService.getById(id);
    }
    return this.localService.getById(id);
  }

  async save(assistant: Assistant): Promise<Assistant> {
    if (this.remoteService) {
      return await this.remoteService.save(assistant);
    }
    return this.localService.save(assistant);
  }

  async saveAll(assistants: Assistant[]): Promise<Assistant[]> {
    if (this.remoteService) {
      return await this.remoteService.saveAll(assistants);
    }
    return this.localService.saveAll(assistants);
  }

  async delete(id: string): Promise<void> {
    if (this.remoteService) {
      await this.remoteService.delete(id);
    } else {
      await this.localService.delete(id);
    }
  }
}
```

### Q1. Exclusive Mode 적용 방식

**질문**: `AssistantService`를 Exclusive Mode로 구현할 때, Remote 연결 실패 시 어떻게 처리할까요?

**선택지**:

- **A. 현재 계획대로 에러를 그대로 throw하여 사용자에게 알림** (권장)
  - 장점: Remote/Local 모드가 명확히 구분됨, 데이터 일관성 보장
  - 단점: Remote 서버 장애 시 사용자가 아무 작업도 못 함
- **B. Remote 실패 시 자동으로 Local로 fallback**
  - 장점: 사용자 경험 향상 (서버 장애에도 작동)
  - 단점: Remote URL 변경 시 레코드 충돌 위험, 동기화 문제 재발

**권장 답변**: A (에러 throw)

  - 조건: Assistant 수가 1000개 이상 예상되는 경우

### Q4. AssistantContext의 `assistants` 배열 제거 시점

  - 향후: 각 컴포넌트가 `useAssistantService()` 훅으로 직접 데이터 페칭
- **B. 이번 작업에서 모든 컴포넌트를 함께 리팩토링**
  - 장점: 완전한 아키텍처 개선
  - 단점: 작업 범위 확대, 리스크 증가

### Q5. 검색 인덱스 초기화 타이밍

**질문**: `LocalAssistantService` 생성자에서 `refreshIndex()`를 즉시 호출하면, DB가 아직 초기화되지 않아 빈 배열로 인덱싱될 수 있습니다. 어떻게 처리할까요?

**선택지**:

- **A. 현재 계획대로 생성자에서 호출, 첫 search() 시 인덱스가 없으면 자동으로 refreshIndex() 재실행** (권장)
  - `search()` 메서드 시작 부분의 `if (!this.searchIndex) await this.refreshIndex()` 로직으로 보완
- **B. Lazy Initialization: 첫 search() 호출 시에만 인덱스 빌드**
  - 장점: DB 초기화 타이밍 문제 회피
  - 단점: 첫 검색이 느려질 수 있음
- **C. AssistantContext 초기화 완료 이벤트를 감지하여 그 이후에 refreshIndex() 실행**
  - 복잡도 증가

**권장 답변**: A (생성자 호출 + search() 시 재실행 보완)
**실제 답변**: A
