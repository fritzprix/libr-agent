## 1. 작업의 목적

### 1.1 비즈니스 목표

- AI Agent의 자율적 작업 수행 효율을 극대화
- 실패 시 적절한 해결 방법을 제시하여 반복 시도 감소
- 성공 시 다음 단계 가이드를 제공하여 워크플로우 연속성 향상

### 1.2 기술적 목표

- 도구 응답에 컨텍스트 기반 액션 가이드 추가
- 에러 메시지에 해결 방법 및 대안 제시
- 응답 데이터 구조 표준화로 일관성 확보

### 1.3 원칙 기반 (idea.md)

- **도구셋 내 완결성**: 다른 도구셋 의존성 없이 자체 완결
- **충분한 정보 제공**: AI Agent가 현재 환경을 정확히 이해할 수 있는 정보
- **자율성 지원**: 실패 시 다음 행동 제안, 성공 시 워크플로우 연계 팁

### 3.2 응답 생성 패턴

**현재 공통 패턴**

```typescript
// 1. 성공 응답 (텍스트만)
return createMCPSuccessToolResult('Operation completed');

// 2. 성공 응답 (구조화 데이터 포함)
return createMCPStructuredToolResult('Success message', { data });

// 3. 에러 응답
return createMCPErrorToolResult('Error message');

// 4. 멀티파트 응답 (UI 리소스 포함)
return createMCPMultipartToolResult([textPart, uiResource], data);
```

**페이징 헬퍼** (`src/lib/db/crud.ts`)

- `createPage<T>(items: T[], page: number, pageSize: number, totalItems: number)`
- 반환 타입: `{ items, page, pageSize, totalItems, totalPages, hasNextPage, hasPreviousPage }`

### 5.1 MCP Manager (`src/lib/web-mcp/modules/mcp-manager/server.ts`)

#### 5.1.1 search_server - 결과 없을 때 개선

**수정 위치**: `searchServer()` 함수 내부, 페이징 결과 생성 후

**현재 코드**:

```typescript

// 단순 결과 반환
return createMCPStructuredToolResult(summary, {
  ...result,
  query: input.query,
  mode: input.searchMode,
});
```

**개선 방향**:

```typescript
const result = normalizePagination(servers, input.page!, input.pageSize!);

// 결과 없을 때 컨텍스트 기반 가이드 제공
if (result.totalItems === 0) {
  const allServers = await mcpService.getAll();
  const totalCount = allServers.length;
  const activeCount = allServers.filter((s) => s.isActive).length;

  const suggestions = [];

  // 1. 검색 모드 전환 제안
  const alternativeMode = input.searchMode === 'bm25' ? 'simple' : 'bm25';
  suggestions.push(`Try searchMode: "${alternativeMode}"`);

  // 2. 조건부 list_servers 제안 (< 20개일 때만)
  if (totalCount < 20) {
    suggestions.push('Use list_servers to browse all servers');
  } else {
    suggestions.push('Refine search with more specific keywords');
  }

  return createMCPStructuredToolResult(
    `No servers found matching "${input.query}".\n` +
      `Database has ${activeCount} active servers (${totalCount} total).\n\n` +
      `Suggestions:\n${suggestions.map((s) => `  - ${s}`).join('\n')}`,
    {
      ...result,
      query: input.query,
      mode: input.searchMode,
      databaseStats: { total: totalCount, active: activeCount },
      suggestions,
    },
  );
}
```

#### 5.2.6 mark_todo - 성공 시 진행률 및 차단 해제 알림

```typescript
// 차단 해제된 Todo 찾기
const unblockedTodos = state.todos.filter(
  (t) =>
    t.status === 'blocked' &&
    t.dependsOn?.includes(id) &&
    t.dependsOn.every((depId) => {
      const dep = state.todos.find((d) => d.id === depId);
      return dep?.status === 'completed';
    }),
);

// 진행률 계산
const completedCount = state.todos.filter(
  (t) => t.status === 'completed',
).length;
const progress = Math.round((completedCount / state.todos.length) * 100);

let message =
  `✓ Todo ${id} marked as ${completed ? 'completed' : 'pending'}.\n\n` +
  `Progress: ${completedCount}/${state.todos.length} (${progress}%)`;

if (unblockedTodos.length > 0) {
  message +=
    `\n\n🔓 Unblocked todos:\n` +
    unblockedTodos.map((t) => `  - [${t.id}] ${t.name}`).join('\n');
}

return createMCPStructuredToolResult(message, {
  success: true,
  id,
  completed,
  progress: {
    completed: completedCount,
    total: state.todos.length,
    percentage: progress,
  },
  unblockedTodos: unblockedTodos.map((t) => ({ id: t.id, name: t.name })),
});
```

```typescript
    suggestions.push('Try removing some tags to broaden search');
  }
  if (query) {
    suggestions.push('Try partial keywords or different terms');
  }
  if (totalCount < 50) {
    suggestions.push('Use list_knowledge to browse all items');
  }

  return createMCPStructuredToolResult(
    `No knowledge items found.\n` +
      `Search: "${query || 'none'}", Tags: [${tags?.join(', ') || 'none'}]\n` +
      `Total items in database: ${totalCount}\n\n` +
      `Suggestions:\n${suggestions.map((s) => `  - ${s}`).join('\n')}`,
    {
      results: [],
      query,
      tags,
      totalAvailable: totalCount,
      suggestions,
    },
  );
}
```

**주요 함수**:

```typescript
export function createPage<T>(
  allItems: T[],
  page: number,
  pageSize: number,
  totalItems: number,
): PaginatedResponse<T> {
  const totalPages = Math.ceil(totalItems / pageSize);
  const startIndex = (page - 1) * pageSize;
  const items = allItems.slice(startIndex, startIndex + pageSize);

  return {
    items,
    page,
    pageSize,
    totalItems,
    totalPages,
    hasNextPage: page < totalPages,
    hasPreviousPage: page > 1,
  };
}
```

```typescript
/**
 * 에러 응답에 suggestions 포함하는 헬퍼
 */
export function createErrorWithSuggestions(
  message: string,
  code: string,
  suggestions: string[],
  additionalData?: Record<string, unknown>,
): MCPResult<unknown> {
  const suggestionsText =
    suggestions.length > 0
      ? `\n\nSuggestions:\n${suggestions.map((s) => `  - ${s}`).join('\n')}`
      : '';

  return createMCPErrorToolResult(message + suggestionsText, {
    error: {
      code,
      suggestions,
      ...additionalData,
    },
  });
}

/**
 * 성공 응답에 nextActions 포함하는 헬퍼
 */
export function createSuccessWithNextActions<T>(
  message: string,
  data: T,
  nextActions: string[],
): MCPResult<T> {
  const actionsText =
    nextActions.length > 0
      ? `\n\nNext steps:\n${nextActions.map((a, i) => `  ${i + 1}. ${a}`).join('\n')}`
      : '';

  return createMCPStructuredToolResult(message + actionsText, {
    ...data,
    nextActions,
  });
}
```
