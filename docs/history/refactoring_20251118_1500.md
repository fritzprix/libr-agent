**Date**: 2025-11-18  
**Target Version**: 0.3.x  
**Priority**: P0 (Critical)

## 📋 목적 (Objectives)

### 핵심 목표

1. Windows 환경에서 Python inline 명령어 실행 실패 문제 해결
2. Long-running 프로세스(서버, watch 모드)의 실시간 로그 스트리밍 지원
3. Sync 모드의 stderr 읽기 버그 수정
4. 파일 기반 I/O의 타이밍 이슈 근본 해결

- AI 에이전트가 Python/Node.js 코드를 안정적으로 실행 가능
- 개발 서버(npm run dev, vite) 실행 및 모니터링 가능

### 데이터 흐름

**Async 모드 실행 흐름**:

```
Agent → execute_shell(cmd, run_mode: async)
  ↓
1. ProcessEntry 생성 (Starting)
  ↓
2. Registry 등록
  ↓
3. tokio::spawn(async {
     status → Running
     spawn_and_stream_to_files(...)
     status → Finished/Failed
   })
  ↓
4. Return process_id immediately
  ↓
Agent → poll_process(process_id, tail: {src, n})
  ↓
5. Registry 조회 → status, sizes
  ↓
6. tail_lines(file_path, n) → read file
  ↓
7. Return status + tail output
```

## 🚨 문제점 상세 분석 (Problem Analysis)

### Issue #1: 따옴표 정규화 버그 (Quote Normalization)

**위치**: `code_execution.rs::normalize_shell_command()`

**현재 코드**:

```rust
#[cfg(windows)]
fn normalize_shell_command(raw_command: &str) -> String {
    let normalized = raw_command.replace('\'', "\"");
    info!("Windows command normalized: {} -> {}", raw_command, normalized);
    normalized
}
```

**문제**:

- 모든 single quote를 double quote로 일괄 변환
- 중첩된 따옴표 구조 파괴
- `python -c "print('test')"` → `python -c "print("test")"`
- Python 파서가 구문 오류로 인식

**영향 범위**:

- ❌ Python inline execution: `python -c "..."`
- ❌ Node.js inline execution: `node -e "..."`
- ❌ 중첩 따옴표를 사용하는 모든 명령어
- ✅ 단순 명령어 (echo, dir): 영향 없음

**로그 증거**:

```log
[14:23:11] Windows command normalized: python -c "print('Python inline test')"
           -> python -c "print("Python inline test")"
[14:23:14] Process exit code: 1
[14:23:14] stderr: 238 bytes written, 0 bytes read
```

### Issue #2: Stderr 파일 읽기 타이밍 버그

**위치**: `code_execution.rs::spawn_and_stream_to_files()`

**현재 코드**:

```rust
// stderr 스트리밍
let stderr_handle = tokio::spawn(async move {
    let mut file = tokio::fs::File::create(&stderr_path).await?;
    let mut buf = vec![0u8; 8192];
    while let Ok(n) = stderr.read(&mut buf).await {
        if n == 0 { break; }
        file.write_all(&buf[..n]).await?;
        // ⚠️ No flush()!
    }
    // ⚠️ File handle dropped here (implicit flush on drop)
    Ok(())
});

// Wait for streaming
stderr_handle.await?;

// ⚠️ Read immediately after spawn completion
let stderr_content = tokio::fs::read_to_string(&stderr_path).await?;
```

**문제**:

1. `File::write_all()` 후 명시적 `flush()` 없음
2. 스트리밍 태스크 완료 직후 파일 읽기 시도
3. 파일 핸들 drop은 비동기적으로 발생 가능
4. Windows 파일 시스템 버퍼링으로 데이터가 디스크에 아직 없을 수 있음

**증상**:

- 로그: "stderr streaming completed, total bytes: 238"
- 로그: "Process output sizes: stdout=0 bytes, stderr=0 bytes"
- 실제 에러 메시지가 사용자에게 전달되지 않음

**영향 범위**:

- Sync 모드: 항상 발생
- Async 모드: poll_process 호출 시점에 따라 발생 가능

### Issue #3: Long-running 프로세스 실시간 출력 부족

**현재 동작**:

```
npm run dev (서버 시작)
  ↓
Async 모드 실행
  ↓
stdout/stderr → 파일에 계속 쓰기
  ↓
Agent: poll_process(process_id, tail: {src: "stdout", n: 20})
  ↓
tail_lines(file_path, 20) → 파일 읽기
  ↓
Return last 20 lines
```

**문제**:

1. **파일 flush 타이밍 불확실**: 프로세스 실행 중 파일 읽기 시 최신 데이터 보장 안 됨
2. **폴링 기반 아키텍처**: Agent가 주기적으로 poll 호출해야 함 (비효율)
3. **지연된 피드백**: 새 로그가 발생해도 다음 poll까지 Agent가 알 수 없음
4. **과도한 폴링 가능성**: Agent가 너무 자주 poll하면 시스템 부하

**영향 받는 시나리오**:

- Development servers: `npm run dev`, `vite`, `webpack-dev-server`
- Watch modes: `tsc --watch`, `jest --watch`
- Long-running scripts: 데이터 처리, 배치 작업
- Continuous output: 진행률 표시, 스트리밍 로그

use tokio::io::AsyncWriteExt;

let stderr_handle = tokio::spawn(async move {
    let file = tokio::fs::File::create(&stderr_path).await?;
    let mut writer = tokio::io::BufWriter::new(file);

    let mut buf = vec![0u8; 8192];
    loop {
        match stderr.read(&mut buf).await {

            Ok(n) => {

#### 2.1. 새로운 데이터 구조 추가

**파일**: `src-tauri/src/mcp/builtin/workspace/terminal_manager.rs`

**추가 코드**:

```rust
use tokio::sync::broadcast;
use std::collections::VecDeque;

/// Real-time streaming handle for background processes
#[derive(Debug)]
pub struct StreamingHandle {
    /// Broadcast channel for real-time stdout
    pub stdout_tx: broadcast::Sender<String>,

    /// Broadcast channel for real-time stderr
    pub stderr_tx: broadcast::Sender<String>,

    /// In-memory circular buffer (last N lines) for fast polling
    pub stdout_buffer: Arc<Mutex<VecDeque<String>>>,
    pub stderr_buffer: Arc<Mutex<VecDeque<String>>>,

    /// Buffer size limit (default: 1000 lines)
    pub buffer_limit: usize,
}

impl StreamingHandle {
    pub fn new(buffer_limit: usize) -> Self {
        let (stdout_tx, _) = broadcast::channel(1000);
        let (stderr_tx, _) = broadcast::channel(1000);

        Self {
            stdout_tx,
            stderr_tx,
            stdout_buffer: Arc::new(Mutex::new(VecDeque::with_capacity(buffer_limit))),
            stderr_buffer: Arc::new(Mutex::new(VecDeque::with_capacity(buffer_limit))),
            buffer_limit,
        }
    }

    /// Add line to buffer (circular, drops oldest if full)
    pub async fn push_stdout(&self, line: String) {
        let mut buffer = self.stdout_buffer.lock().await;
        if buffer.len() >= self.buffer_limit {
            buffer.pop_front();
        }
        buffer.push_back(line.clone());
        drop(buffer);

        let _ = self.stdout_tx.send(line);
    }

    pub async fn push_stderr(&self, line: String) {
        let mut buffer = self.stderr_buffer.lock().await;
        if buffer.len() >= self.buffer_limit {
            buffer.pop_front();
        }
        buffer.push_back(line.clone());
        drop(buffer);

        let _ = self.stderr_tx.send(line);
    }

    /// Get last N lines from buffer
    pub async fn get_tail(&self, stream: StreamType, n: usize) -> Vec<String> {
        let buffer = match stream {
            StreamType::Stdout => self.stdout_buffer.lock().await,
            StreamType::Stderr => self.stderr_buffer.lock().await,
        };

        buffer.iter()
            .rev()
            .take(n)
            .rev()
            .cloned()
            .collect()
    }
}

#[derive(Debug, Clone, Copy)]
pub enum StreamType {
    Stdout,
    Stderr,
}

/// Enhanced ProcessRegistryData with streaming support
pub struct ProcessRegistryData {
    pub entries: HashMap<String, ProcessEntry>,
    pub cancellation_tokens: HashMap<String, CancellationToken>,
    pub streaming_handles: HashMap<String, Arc<StreamingHandle>>,  // NEW
}
```

#### 2.2. 하이브리드 스트리밍 함수 구현

**파일**: `src-tauri/src/mcp/builtin/workspace/code_execution.rs`

**새 함수 추가**:

```rust
use tokio::io::{AsyncBufReadExt, BufReader};

/// Spawn process and stream output to both channels and files
/// Returns (pid, exit_code, streaming_handle)
async fn spawn_and_stream_hybrid(
    mut cmd: tokio::process::Command,
    stdout_path: PathBuf,
    stderr_path: PathBuf,
    process_label: String,
    cancel_token: CancellationToken,
) -> Result<(Option<u32>, Option<i32>, Arc<StreamingHandle>), String> {
    use std::process::Stdio;

    cmd.stdout(Stdio::piped());
    cmd.stderr(Stdio::piped());
    cmd.stdin(Stdio::null());

    let mut child = cmd.spawn().map_err(|e| format!("Failed to spawn: {e}"))?;
    let pid = child.id();

    // Create streaming handle
    let streaming = Arc::new(StreamingHandle::new(1000));

    // Stdout streaming: line-by-line
    let stdout_handle = if let Some(stdout) = child.stdout.take() {
        let streaming_clone = streaming.clone();
        let stdout_path_clone = stdout_path.clone();
        let label = process_label.clone();
        let cancel_clone = cancel_token.clone();

        tokio::spawn(async move {
            let reader = BufReader::new(stdout);
            let mut lines = reader.lines();
            let mut file = tokio::fs::File::create(&stdout_path_clone).await?;
            let mut writer = tokio::io::BufWriter::new(file);

            loop {
                tokio::select! {
                    _ = cancel_clone.cancelled() => break,
                    line_result = lines.next_line() => {
                        match line_result {
                            Ok(Some(line)) => {
                                // 1. Send to broadcast channel + buffer
                                streaming_clone.push_stdout(line.clone()).await;

                                // 2. Write to file
                                writer.write_all(line.as_bytes()).await?;
                                writer.write_all(b"\n").await?;
                                writer.flush().await?;  // Explicit flush each line
                            }
                            Ok(None) => break,  // EOF
                            Err(e) => {
                                tracing::warn!("Stdout read error: {}", e);
                                break;
                            }
                        }
                    }
                }
            }

            writer.flush().await?;
            drop(writer);

            info!("Process {} stdout streaming completed", label);
            Ok::<_, std::io::Error>(())
        })
    } else {
        tokio::spawn(async { Ok(()) })
    };

    // Stderr streaming: same pattern
    let stderr_handle = if let Some(stderr) = child.stderr.take() {
        let streaming_clone = streaming.clone();
        let stderr_path_clone = stderr_path.clone();
        let label = process_label.clone();
        let cancel_clone = cancel_token.clone();

        tokio::spawn(async move {
            let reader = BufReader::new(stderr);
            let mut lines = reader.lines();
            let mut file = tokio::fs::File::create(&stderr_path_clone).await?;
            let mut writer = tokio::io::BufWriter::new(file);

            loop {
                tokio::select! {
                    _ = cancel_clone.cancelled() => break,
                    line_result = lines.next_line() => {
                        match line_result {
                            Ok(Some(line)) => {
                                streaming_clone.push_stderr(line.clone()).await;
                                writer.write_all(line.as_bytes()).await?;
                                writer.write_all(b"\n").await?;
                                writer.flush().await?;
                            }
                            Ok(None) => break,
                            Err(e) => {
                                tracing::warn!("Stderr read error: {}", e);
                                break;
                            }
                        }
                    }
                }
            }

            writer.flush().await?;
            drop(writer);

            info!("Process {} stderr streaming completed", label);
            Ok::<_, std::io::Error>(())
        })
    } else {
        tokio::spawn(async { Ok(()) })
    };

    // Wait for process
    let exit_code = tokio::select! {
        _ = cancel_token.cancelled() => {
            let _ = child.kill().await;
            None
        }
        result = child.wait() => {
            result.ok().and_then(|s| s.code())
        }
    };

    // Wait for streaming tasks
    let _ = stdout_handle.await;
    let _ = stderr_handle.await;

    info!("Process {} completed with exit code {:?}", process_label, exit_code);

    Ok((pid, exit_code, streaming))
}
```

    let registry = self.process_registry.clone();
    let pid_copy = process_id.clone();

    tokio::spawn(async move {

        {
            let mut reg = registry.write().await;

            stderr_path.clone(),

            cancel_token,

        let mut reg = registry.write().await;
        if let Some(entry) = reg.entries.get_mut(&pid_copy) {

                    } else {
                        ProcessStatus::Failed

            }
            if let Ok(meta) = tokio::fs::metadata(&stderr_path).await {
                entry.stderr_size = meta.len();
            }
        }

        reg.cancellation_tokens.remove(&pid_copy);
    });

```rust
pub async fn handle_poll_process(&self, args: Value) -> Result<MCPResult, String> {
    let process_id = args.get("process_id").and_then(|v| v.as_str())
        .ok_or("Missing required parameter: process_id")?;

    // ... (세션 검증 코드 동일) ...

    // Get entry and streaming handle
    let (entry_clone, streaming_handle) = {
        let mut registry = self.process_registry.write().await;

        let entry = registry.entries.get_mut(process_id)
            .ok_or("Process not found")?;

        // Update poll tracking
        let now = chrono::Utc::now();
        entry.last_poll_at = Some(now);
        entry.poll_count += 1;

        let is_running = matches!(entry.status, ProcessStatus::Running);
        if is_running {
            if entry.first_running_poll_at.is_none() {
                entry.first_running_poll_at = Some(now);
            }
            entry.consecutive_running_polls += 1;
        } else {
            entry.consecutive_running_polls = 0;
            entry.first_running_poll_at = None;
        }

        let should_guide = is_running && entry.consecutive_running_polls >= 5;
        let entry_clone = entry.clone();

        // Get streaming handle if available
        let handle = registry.streaming_handles.get(process_id).cloned();

        (entry_clone, handle)
    };

    // Build response
    let mut response = serde_json::json!({
        "process_id": entry_clone.id,
        "status": format!("{:?}", entry_clone.status).to_lowercase(),
        "command": entry_clone.command,
        "pid": entry_clone.pid,
        "exit_code": entry_clone.exit_code,
        "stdout_size": entry_clone.stdout_size,
        "stderr_size": entry_clone.stderr_size,
        "streaming_available": streaming_handle.is_some(),
    });

    // Handle tail request
    if let Some(tail_obj) = args.get("tail").and_then(|v| v.as_object()) {
        let src = tail_obj.get("src").and_then(|v| v.as_str()).unwrap_or("stdout");
        let n = tail_obj.get("n").and_then(|v| v.as_u64()).unwrap_or(10) as usize;

        let lines = if let Some(handle) = &streaming_handle {
            // Fast path: get from in-memory buffer
            let stream_type = if src == "stdout" {
                terminal_manager::StreamType::Stdout
            } else {
                terminal_manager::StreamType::Stderr
            };
            handle.get_tail(stream_type, n).await
        } else {
            // Fallback: read from file (process finished or old entry)
            let file_path = if src == "stdout" {
                PathBuf::from(&entry_clone.stdout_path)
            } else {
                PathBuf::from(&entry_clone.stderr_path)
            };
            terminal_manager::tail_lines(&file_path, n).await.unwrap_or_default()
        };

        response["tail"] = serde_json::json!({
            "src": src,
            "lines": lines,
            "source": if streaming_handle.is_some() { "buffer" } else { "file" },
        });
    }

    Ok(MCPResult::success(&serde_json::to_string_pretty(&response)?))
}
```
