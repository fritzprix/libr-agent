# Refactoring Plan: Builtin Tool Response Format Alignment (Legacy → Rust)

**Date:** 2024-12-28  
**Target Version:** 0.4.0  
**Priority:** CRITICAL  
**Status:** Planning

---

## 목적 (Purpose)

Web-MCP (TypeScript) builtin 도구에서 Rust builtin 도구로 마이그레이션하면서 **두 가지 치명적 문제**가 발생했습니다:

1. **응답 형식 불일치**: 텍스트 콘텐츠 누락 및 가이던스 정보 부재로 LLM 성능 저하
2. **도구명 불일치**: LLM에 노출되는 도구명과 실제 처리 시 인식하는 도구명이 달라 도구 호출 실패

Legacy 응답 형식은 **prompt tuning의 결과물**이므로, Rust 구현에서도 **동일한 응답 형식과 도구명 규칙을 유지**해야 합니다.

### 핵심 문제

#### A. 응답 형식 문제

1. **텍스트 콘텐츠 누락**: UI 도구들이 HTML 리소스만 반환하고 설명 텍스트가 없음
2. **가이던스 정보 부재**: `nextActions`, `suggestions`, zero-result 메시지 등이 누락됨
3. **응답 메시지 간소화**: Legacy의 상세한 멀티라인 메시지가 단순 문자열로 축약됨
4. **변경 추적 누락**: 업데이트 작업에서 무엇이 변경되었는지 알려주지 않음

#### B. 도구명 불일치 문제 (CRITICAL - 신규 발견)

5. **도구 등록 시 prefix 누락**: Builtin 도구가 `builtin_<alias>__` prefix 없이 등록됨
6. **도구명 형식 혼재**: snake_case (`prompt_user`) vs camelCase (`executeWindowsCmd`) 혼용
7. **도구 해석(resolution) 실패**: LLM이 호출한 도구를 TypeScript에서 찾지 못함 (`availableTools: []`)
8. **잘못된 라우팅**: Builtin 도구가 "external"로 오인되어 불필요한 frontend 경유

## 현재 상태 / 문제점

### 0. 도구명 불일치 문제 (CRITICAL - 최우선 수정 필요)

#### **문제 개요**

LLM에게 제공되는 도구명과 실제 도구 호출 처리 시 인식하는 도구명이 불일치하여 **모든 builtin 도구 호출이 실패**하고 있습니다.

**증상:**

```
[WARN] [useUnifiedMCP] Could not resolve tool name
{"calledName":"prompt_user","availableTools":[]}

[WARN] [useUnifiedMCP] Could not resolve tool: prompt_user (namespace: external)
{"availableTools":[],"totalAvailableTools":0}
```

#### **Root Cause 분석**

**도구 흐름:**

```
1. Rust 도구 정의 (ui/mod.rs)
   → tools() returns [name: "prompt_user"]  ❌ NO PREFIX

2. 도구 수집 (MCPServiceProxy)
   → get_builtin_server_tools()  ❌ PREFIX 추가 안됨
   → Returns: ["prompt_user", "executeWindowsCmd", ...]

3. LLM에 전송 (AgentSessionManager)
   → collect_available_tools()
   → emit('llm:completion-request', {availableTools: [...]})
   → LLM receives: ["prompt_user", ...]  ❌ WITHOUT PREFIX

4. LLM 응답
   → tool_calls: [{name: "prompt_user"}]

5. Rust 라우팅
   → "prompt_user"를 "external" 도구로 오인  ❌ WRONG
   → emit('tool:execute-request', {toolName: "prompt_user"})

6. TypeScript Resolution (useUnifiedMCP)
   → resolveToolName("prompt_user")
   → toolTypeMap is EMPTY  ❌ CRITICAL
   → availableTools array is EMPTY  ❌ CRITICAL
   → Resolution FAILS
```

**핵심 문제 4가지:**

1. **Prefix 누락**: 도구 등록 시 `builtin_<alias>__` prefix가 추가되지 않음
2. **형식 혼재**: snake_case (`prompt_user`) vs camelCase (`executeWindowsCmd`) 혼용
3. **빈 toolTypeMap**: TypeScript에서 도구 맵이 비어있어 모든 resolution 실패
4. **잘못된 라우팅**: Builtin 도구가 "external"로 오인되어 불필요한 frontend 경유

  withMessage(msg: string): this {
    /* ... */
  }
  withSuggestions(suggestions: string[]): this {
    /* ... */
  }
  withNextActions(actions: string[]): this {
    /* ... */
  }

  asSuccess(): MCPResult<T & { nextActions?: string[] }> {
    const actionsText =
      this.nextActions.length > 0
        ? `\n\nNext steps:\n${this.nextActions.map((a, i) => `  ${i + 1}. ${a}`).join('\n')}`
        : '';

    const suggestionsText =
      this.suggestions.length > 0
        ? `\n\nSuggestions:\n${this.suggestions.map((s) => `  - ${s}`).join('\n')}`
        : '';

    return createMCPStructuredToolResult(
      this.message + actionsText + suggestionsText,
      {
        ...this.data,
        nextActions: this.nextActions.length > 0 ? this.nextActions : undefined,
      },
    );
  }
}

#### 0.1 도구 수집 시 Prefix 추가

**파일:** `src-tauri/src/agent/mcp_service_proxy.rs`

**변경 전 (라인 추정 위치):**

**변경 후:**

```rust
pub fn get_builtin_server_tools(&self, server_id: &str) -> Vec<MCPTool> {
    if let Some(server) = self.builtin_registry.get_server(server_id) {
        let tools = server.tools();
        let alias = server_id; // Service alias from registry

        // Add builtin_ prefix to all tool names if not already present
        tools.into_iter().map(|mut tool| {
            if !tool.name.starts_with("builtin_") {
                // Extract base name and convert to camelCase if needed
                let base_name = tool.name.clone();
                tool.name = format!("builtin_{}\__{}", alias, base_name);
            }
            tool
        }).collect()
    } else {
        Vec::new()
    }
}
```

**목적:** 모든 builtin 도구가 `builtin_<alias>__<toolName>` 형식으로 LLM에 전달되도록 보장

pub async fn route_tool_call(&self, session_id: &str, tool_name: &str, args: Value)
    -> Result<MCPResult, String> {

    // Check if tool has builtin_ prefix
    if tool_name.starts_with("builtin_") {
        // Extract service alias and tool name
        if let Some((alias, tool_name_only)) = parse_builtin_tool_name(tool_name) {
            // Route to Rust builtin server directly
            return self.call_builtin_tool(session_id, alias, tool_name_only, args).await;
        }
    }

    // Check unprefixed builtin tools (legacy support)
    if let Some(builtin_result) = self.try_builtin_tools_legacy(session_id, tool_name, args.clone()).await {
        return builtin_result;
    }

    // Fall back to external MCP (frontend)
    self.call_external_tool_via_frontend(session_id, tool_name, args).await
}

fn parse_builtin_tool_name(full_name: &str) -> Option<(&str, &str)> {
    // Parse "builtin_<alias>__<toolName>" into (alias, toolName)
    let parts: Vec<&str> = full_name.split("__").collect();
    if parts.len() == 2 {
        let alias = parts[0].strip_prefix("builtin_")?;
        let tool_name = parts[1];
        Some((alias, tool_name))
    } else {
        None
    }
}

use crate::mcp::types::{MCPContent, MCPResult};
use serde_json::{json, Value};

/// Fluent API for constructing MCP tool responses with consistent formatting
///
/// Mirrors the TypeScript MCPResponseBuilder pattern for compatibility
///
/// # Examples
///
/// ```
/// // Success with next actions
/// ResponseBuilder::new()
///     .with_data(json!({"id": "123", "name": "test"}))
///     .with_message("Assistant created: \"test\" (ID: 123)")
///     .with_next_actions(vec![
///         "Use updateAssistant to modify settings",
///         "Connect MCP servers with connect_server tool"
///     ])
///     .build_success();
///
/// // Error with suggestions
/// ResponseBuilder::new()
///     .with_data(json!({"requestedId": "unknown"}))
///     .with_message("Assistant with ID unknown not found.")
///     .with_suggestions(vec![
///         "Use listAssistants to see all available assistants",
///         "Check the assistant ID spelling"
///     ])
///     .build_error();
/// ```
pub struct ResponseBuilder {
    message: String,
    content_parts: Vec<MCPContent>,
    structured_data: Option<Value>,
    next_actions: Vec<String>,
    suggestions: Vec<String>,
}

impl ResponseBuilder {
    pub fn new() -> Self {
        Self {
            message: String::new(),
            content_parts: Vec::new(),
            structured_data: None,
            next_actions: Vec::new(),
            suggestions: Vec::new(),
        }
    }

    /// Set the main response message (base text before formatting)
    pub fn with_message(mut self, message: impl Into<String>) -> Self {
        self.message = message.into();
        self
    }

    /// Add structured data (equivalent to structuredContent in Legacy)
    pub fn with_data(mut self, data: Value) -> Self {
        self.structured_data = Some(data);
        self
    }

    /// Add next action guidance (shown after success message)
    pub fn with_next_actions(mut self, actions: Vec<impl Into<String>>) -> Self {
        self.next_actions = actions.into_iter().map(|a| a.into()).collect();
        self
    }

    /// Add suggestions for error recovery or usage improvement
    pub fn with_suggestions(mut self, suggestions: Vec<impl Into<String>>) -> Self {
        self.suggestions = suggestions.into_iter().map(|s| s.into()).collect();
        self
    }

    /// Add a text content part (for multipart responses)
    pub fn with_text_content(mut self, text: impl Into<String>) -> Self {
        self.content_parts.push(MCPContent::Text {
            text: text.into(),
        });
        self
    }

    /// Add a resource content part (for UI resources)
    pub fn with_resource(mut self, resource: Value) -> Self {
        self.content_parts.push(MCPContent::Resource { resource });
        self
    }

    /// Build final formatted text with nextActions and suggestions
    fn build_formatted_text(&self) -> String {
        let mut text = self.message.clone();

        // Add next actions (Legacy format: "\n\nNext steps:\n  1. ...\n  2. ...")
        if !self.next_actions.is_empty() {
            text.push_str("\n\nNext steps:");
            for (i, action) in self.next_actions.iter().enumerate() {
                text.push_str(&format!("\n  {}. {}", i + 1, action));
            }
        }

        // Add suggestions (Legacy format: "\n\nSuggestions:\n  - ...\n  - ...")
        if !self.suggestions.is_empty() {
            text.push_str("\n\nSuggestions:");
            for suggestion in &self.suggestions {
                text.push_str(&format!("\n  - {}", suggestion));
            }
        }

        text
    }

    /// Build as success response
    pub fn build_success(mut self) -> MCPResult {
        let formatted_text = self.build_formatted_text();

        // If no content parts were added manually, create text content from message
        if self.content_parts.is_empty() {
            self.content_parts.push(MCPContent::Text {
                text: formatted_text,
            });
        } else {
            // If manual content parts exist (e.g., for UI resources),
            // prepend the formatted text
            self.content_parts.insert(
                0,
                MCPContent::Text {
                    text: formatted_text,
                },
            );
        }

        // Add nextActions to structured data if provided
        let structured = if let Some(mut data) = self.structured_data {
            if !self.next_actions.is_empty() {
                if let Some(obj) = data.as_object_mut() {
                    obj.insert(
                        "nextActions".to_string(),
                        json!(self.next_actions),
                    );
                }
            }
            Some(data)
        } else if !self.next_actions.is_empty() {
            Some(json!({ "nextActions": self.next_actions }))
        } else {
            None
        };

        MCPResult {
            content: Some(self.content_parts),
            structured_content: structured,
            is_error: Some(false),
        }
    }

    /// Build as error response
    pub fn build_error(mut self) -> MCPResult {
        let formatted_text = self.build_formatted_text();

        // Add error data with suggestions to structured content
        let error_data = json!({
            "code": "ERROR", // Can be extended with specific error codes
            "suggestions": if !self.suggestions.is_empty() {
                Some(self.suggestions.clone())
            } else {
                None
            }
        });

        let structured = if let Some(mut data) = self.structured_data {
            if let Some(obj) = data.as_object_mut() {
                obj.insert("error".to_string(), error_data);
            }
            Some(data)
        } else {
            Some(json!({ "error": error_data }))
        };

        MCPResult {
            content: Some(vec![MCPContent::Text {
                text: formatted_text,
            }]),
            structured_content: structured,
            is_error: Some(true),
        }
    }
}

impl Default for ResponseBuilder {
    fn default() -> Self {
        Self::new()
    }
}

| → 0.3       | 도구 라우팅 핸들러 업데이트 (하위 호환성)          | 1시간       | CRITICAL     | 0.2               |
| → 0.4       | Workspace 도구 라우팅 업데이트                     | 30분        | HIGH         | -                 |
| → 0.5       | TypeScript 도구 맵 채우기 (builtInRustTools)       | 1-2시간     | CRITICAL     | -                 |
| → 0.6       | Rust 도구 라우팅 개선 (builtin\_ prefix 인식)      | 1시간       | HIGH         | 0.1               |
