# Refactoring: Fix External MCP Result Serialization

**Status**: ✅ COMPLETED AND VALIDATED

## Objective

Fix the "double serialization" bug where `CallToolResult` is converted to a generic JSON Value instead of being passed as a typed `ToolCall` result. This ensures the frontend receives the correct JSON structure for External MCP tools.

## Problem Analysis

### Root Cause

- **Location**: `stdio_manager.rs` (line 224) and `http_manager.rs` (line 194)
- **Issue**: Used `serde_json::to_value(&call_result)` wrapped in `MCPResponseResult::Generic`
- **Impact**: Treated tool results as opaque JSON blobs, causing type mismatch in frontend expecting `ToolCall` structure
- **Symptom**: External MCP tool outputs arrived as strings instead of structured objects

### Target Architecture

Use `MCPResponseResult::ToolCall` which wraps `crate::mcp::types::MCPResult`, providing proper type safety and structure.

### Actual Implementation

#### Content Mapping Strategy

Since `rmcp::types::CallToolResult` uses `Annotated<RawContent>` (not enum variants), implemented JSON-based conversion:

```rust
let local_content: Vec<crate::mcp::types::MCPContent> = call_result
    .content
    .into_iter()
    .filter_map(|c| {
        // Serialize rmcp Content to JSON for type inspection
        let json_val = serde_json::to_value(&c).ok()?;

        // Extract type field and route to appropriate handler
        if let Some(type_str) = json_val.get("type").and_then(|v| v.as_str()) {
            match type_str {
                "text" => {
                    let text = json_val.get("text")?.as_str()?.to_string();
                    Some(crate::mcp::types::MCPContent::Text { text })
                },
                "image" => {
                    let data = json_val.get("data")?.as_str()?.to_string();
                    let mime_type = json_val.get("mimeType")?.as_str()?.to_string();
                    Some(crate::mcp::types::MCPContent::Image { data, mime_type })
                },
                "resource" => {
                    Some(crate::mcp::types::MCPContent::Resource {
                        resource: json_val.clone(),
                        service_info: crate::mcp::types::ServiceInfo {
                            server_name: server_name.to_string(),
                            tool_name: tool_name.to_string(),
                            backend_type: "ExternalMCP".to_string(),
                        }
                    })
                },
                _ => None,
            }
        } else {
            None
        }
    })
    .collect();
```

#### Response Construction

```rust
let mcp_result = crate::mcp::types::MCPResult {
    content: Some(local_content),
    structured_content: None,
    is_error: call_result.is_error,
};

MCPResponse {
    jsonrpc: "2.0".to_string(),
    id: Some(crate::mcp::types::JsonRpcId::String(
        uuid::Uuid::new_v4().to_string(),
    )),
    result: Some(MCPResponseResult::ToolCall(mcp_result)),
    error: None,
}
```
