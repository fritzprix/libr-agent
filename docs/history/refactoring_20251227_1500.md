# Agent V2 Frontend MVP Implementation

## 작업의 목적

백엔드 인프라가 100% 완료된 Agent V2 시스템의 기능 검증을 위한 최소 기능 프론트엔드 UI 구현.

**핵심 목표:**

1. 백엔드 이벤트 루프 및 툴 실행 검증
2. AgentSessionProvider, AgentChatProvider의 실제 동작 확인
3. Rust ↔ TypeScript 간 IPC 통신 검증
4. 복잡한 UI 구현 없이 핵심 기능 테스트에 집중

**비목표 (Phase 2 이후로 연기):**

- 고도화된 UI/UX
- V1 Chat UI의 모든 기능 복제
- 복잡한 메시지 렌더링 (tool call 시각화 등)
- Streaming indicator, 고급 에러 핸들링 UI

## 관련 코드의 구조 및 동작 방식 Summary

### V1 (Legacy) 구조

```
Route: /chat/* → ChatContainer
  ↓
ChatContainer → currentSession 체크
  ↓
currentSession 있음 → ChatRouter → Chat (compound component)
currentSession 없음 → StartChatView

Chat (compound component):
- Chat.Header: 세션 정보, 설정 버튼
- Chat.Messages: 메시지 목록, 스트리밍 표시
- Chat.Input: 사용자 입력, 툴 트리거
```

**데이터 흐름 (V1)**:

```
User Input → ChatContext → useAIService → AIServiceFactory → Provider API
           ↓
      IndexedDB 저장
```

### V2 (Agent) 목표 구조

```
Route: /agent/* → AgentContainer
  ↓
AgentContainer → currentSession 체크 (AgentSessionProvider)
  ↓
currentSession 있음 → AgentChatView (Simple MVP)
currentSession 없음 → StartAgentView

AgentChatView (Simple MVP):
- 기본 메시지 리스트 (role별 좌우 정렬)
- 간단한 텍스트 입력 (<input>)
- Submit/Cancel 버튼
```

**데이터 흐름 (V2)**:

```
User Input → AgentChatProvider.submit()
           → invoke('agent_send_message')
           → Rust AgentSessionManager
           → Tool 실행 + LLM 호출 (Backend에서 자동)
           → emit 'agent:event'
           → AgentChatProvider 리스너 → 메시지 재로드
           → UI 업데이트
```

**핵심 차이점**:

- V1: 프론트엔드에서 툴 실행 루프 관리
- V2: 백엔드에서 모든 오케스트레이션 처리, 프론트엔드는 이벤트만 수신

### 3. StartAgentView 생성 (NEW)

**파일**: `src/features/agent/StartAgentView.tsx` (신규)

**핵심 기능**:

- Assistant 목록 표시 (useAssistantContext 재사용)
- Assistant 선택
- "Start Agent Session" 버튼
- 세션 생성 후 리다이렉트

```tsx
import { useState } from 'react';
import { useNavigate } from 'react-router';
import { Button } from '@/components/ui';
import { useAssistantContext } from '@/context/AssistantContext';
import { useAgentSessionContext } from '@/context/AgentSessionContext';
import { getLogger } from '@/lib/logger';
import { toast } from 'sonner';

const logger = getLogger('StartAgentView');

/**
 * Start Agent View (Simple MVP)
 *
 * Minimal UI for creating a new agent session.
 */
export default function StartAgentView() {
  const navigate = useNavigate();
  const { assistants } = useAssistantContext();
  const { createSession, isLoading, error } = useAgentSessionContext();
  const [selectedAssistantId, setSelectedAssistantId] = useState<string | null>(
    null,
  );

  const handleStartSession = async () => {
    const assistant = assistants.find((a) => a.id === selectedAssistantId);
    if (!assistant) {
      toast.error('Please select an assistant');
      return;
    }

    try {
      const session = await createSession({ assistant });
      logger.info('Agent session created', { sessionId: session.id });
      toast.success('Agent session started');
      navigate(`/agent/chat/${session.id}`);
    } catch (err) {
      logger.error('Failed to create agent session', err);
      toast.error('Failed to start agent session');
    }
  };

  return (
    <div className="flex flex-col items-center justify-center h-full p-8">
      <h1 className="text-2xl font-bold mb-8">Start Agent Session</h1>

      {/* Assistant List */}
      <div className="w-full max-w-md space-y-4">
        {assistants.map((assistant) => (
          <button
            key={assistant.id}
            onClick={() => setSelectedAssistantId(assistant.id)}
            className={`w-full p-4 text-left border rounded-lg transition-colors ${
              selectedAssistantId === assistant.id
                ? 'border-blue-500 bg-blue-500/10'
                : 'border-gray-700 hover:border-gray-600'
            }`}
          >
            <div className="font-semibold">{assistant.name}</div>
            {assistant.prompt && (
              <div className="text-sm text-gray-400 mt-1 line-clamp-2">
                {assistant.prompt}
              </div>
            )}
          </button>
        ))}
      </div>

      {/* Start Button */}
      <Button
        onClick={handleStartSession}
        disabled={!selectedAssistantId || isLoading}
        className="mt-8 px-8 py-2"
      >
        {isLoading ? 'Starting...' : 'Start Agent Session'}
      </Button>

      {/* Error Display */}
      {error && <div className="mt-4 text-red-500 text-sm">Error: {error}</div>}
    </div>
  );
}
```

### 4. AgentChatView 생성 (NEW)

**파일**: `src/features/agent/AgentChatView.tsx` (신규)

**핵심 기능**:

- 메시지 목록 표시 (role별 좌우 정렬)
- 텍스트 입력 (<input>)
- Send/Cancel 버튼
- 로딩/에러 상태 표시

```tsx
import { useState } from 'react';
import { Button } from '@/components/ui';
import { useAgentChat } from '@/context/AgentChatContext';
import { useAgentSessionContext } from '@/context/AgentSessionContext';
import { getLogger } from '@/lib/logger';
import { Message } from '@/models/chat';

const logger = getLogger('AgentChatView');

/**
 * Agent Chat View (Simple MVP)
 *
 * Minimal UI for agent chat interaction.
 * Focuses on core functionality testing without complex UI.
 */
export default function AgentChatView() {
  const { currentSession } = useAgentSessionContext();
  const { messages, isLoading, error, workflowStatus, submit, cancel } =
    useAgentChat();
  const [input, setInput] = useState('');

  const handleSubmit = async () => {
    if (!input.trim() || !currentSession?.id) return;

    const message: Message = {
      id: crypto.randomUUID(),
      sessionId: currentSession.id,
      threadId: currentSession.id,
      role: 'user',
      content: [{ type: 'text', text: input }],
      createdAt: new Date(),
    };

    logger.debug('Submitting message', { messageId: message.id });
    setInput('');
    await submit(message);
  };

  const handleKeyDown = (e: React.KeyboardEvent<HTMLInputElement>) => {
    if (e.key === 'Enter' && !e.shiftKey) {
      e.preventDefault();
      handleSubmit();
    }
  };

  return (
    <div className="flex flex-col h-full">
      {/* Header */}
      <div className="flex items-center justify-between p-4 border-b border-gray-700">
        <div>
          <h2 className="text-lg font-semibold">
            {currentSession?.name || 'Agent Session'}
          </h2>
          <div className="text-sm text-gray-400">
            Status:{' '}
            <span className={getStatusColor(workflowStatus)}>
              {workflowStatus}
            </span>
          </div>
        </div>
        <Button
          onClick={cancel}
          disabled={workflowStatus !== 'busy'}
          variant="outline"
          size="sm"
        >
          Cancel
        </Button>
      </div>

      {/* Messages */}
      <div className="flex-1 overflow-y-auto p-4 space-y-4">
        {messages.map((msg) => (
          <div
            key={msg.id}
            className={`flex ${msg.role === 'user' ? 'justify-end' : 'justify-start'}`}
          >
            <div
              className={`inline-block max-w-[70%] p-3 rounded-lg ${
                msg.role === 'user'
                  ? 'bg-blue-600 text-white'
                  : 'bg-gray-800 text-gray-100'
              }`}
            >
              <div className="text-xs font-semibold mb-1 opacity-70">
                {msg.role.toUpperCase()}
              </div>
              <div className="whitespace-pre-wrap">
                {msg.content[0]?.type === 'text' && msg.content[0].text}
                {msg.content[0]?.type === 'tool_use' && (
                  <span className="text-yellow-400">
                    [Tool: {msg.content[0].name}]
                  </span>
                )}
                {msg.content[0]?.type === 'tool_result' && (
                  <span className="text-green-400">
                    [Tool Result: {msg.content[0].tool_use_id}]
                  </span>
                )}
              </div>
            </div>
          </div>
        ))}

        {/* Loading Indicator */}
        {isLoading && (
          <div className="flex justify-start">
            <div className="inline-block p-3 bg-gray-800 rounded-lg">
              <div className="flex items-center space-x-2">
                <div className="w-2 h-2 bg-gray-400 rounded-full animate-pulse" />
                <div className="w-2 h-2 bg-gray-400 rounded-full animate-pulse delay-75" />
                <div className="w-2 h-2 bg-gray-400 rounded-full animate-pulse delay-150" />
              </div>
            </div>
          </div>
        )}
      </div>

      {/* Error Display */}
      {error && (
        <div className="px-4 py-2 bg-red-900/20 border-t border-red-900">
          <div className="text-red-400 text-sm">Error: {error}</div>
        </div>
      )}

      {/* Input */}
      <div className="p-4 border-t border-gray-700">
        <div className="flex items-center space-x-2">
          <input
            type="text"
            value={input}
            onChange={(e) => setInput(e.target.value)}
            onKeyDown={handleKeyDown}
            placeholder="Type your message..."
            disabled={isLoading}
            className="flex-1 px-4 py-2 bg-gray-900 border border-gray-700 rounded-lg focus:outline-none focus:border-blue-500 disabled:opacity-50"
          />
          <Button onClick={handleSubmit} disabled={!input.trim() || isLoading}>
            Send
          </Button>
        </div>
      </div>
    </div>
  );
}

function getStatusColor(status: string): string {
  switch (status) {
    case 'idle':
      return 'text-gray-400';
    case 'busy':
      return 'text-yellow-400';
    case 'paused':
      return 'text-blue-400';
    case 'error':
      return 'text-red-400';
    default:
      return 'text-gray-400';
  }
}
```
