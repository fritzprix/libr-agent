## 2026-02-22

### SP6 — Session Request Cancel 계층간 격리 ✅

**Problem:** Parent session cancel이 `awaitAgent`/`pollProcess` 내부에서 최대 30초간 block — child 완료를 wait하는 loop이 heartbeat까지 sleep하기 때문.

**Solution:** Dual-notifier `tokio::select!` 패턴으로 parent cancel 시 즉시 탈출.

**Files changed:**
- `src-tauri/src/state.rs` — `ACTIVE_SESSIONS` global + `get_session_cancel_pending()`
- `src-tauri/src/lifecycle/app_setup.rs` — `init_active_sessions()` 호출
- `src-tauri/src/agent/workflow.rs` — `cancel_workflow` deferred path에 `notify_status_change` 추가
- `src-tauri/src/mcp/builtin/session_api/handlers.rs` — `wait_until_session_terminal` dual-notifier 구현

**Regression tests:** `src-tauri/src/agent/session_bus.rs` — 4 `#[tokio::test]` cases (SP6 block)

→ Full architecture doc: [docs/architecture/session-cancel-isolation.md](../architecture/session-cancel-isolation.md)

### SP7 — Session 삭제 시 하위 요소 정리 옵션 ✅

**Problem:** Session 삭제 시 자식 sessions가 orphan으로 남음 + UI에서도 cascade 제거 안 됨.

**Solution:** 두 가지 삭제 옵션 — cascade (BFS 전체 트리 삭제) vs. orphan (직접 자식만 top-level 승격).

**Files changed:**
- `src-tauri/src/repositories/session_repository.rs` — `orphan_and_delete_session` trait + SQLite impl
- `src-tauri/src/repositories/in_memory_session_repository.rs` — in-memory impl
- `src-tauri/src/agent/session_manager.rs` — `delete_session_only`
- `src-tauri/src/commands/agent_commands.rs` + `src-tauri/src/lib.rs` — `agent_delete_session_only` Tauri command
- `src/lib/backend/session-crud.ts` — `deleteSessionOnly`
- `src/context/AgentSessionListContext.tsx` — BFS cascade UI removal (bug fix) + `deleteSessionOnly`
- `src/features/agent/components/SessionCard.tsx` — conditional 2-option confirm UI
- `src/features/agent/components/SessionHistoryPanel.tsx` + `src/features/history/History.tsx` — prop chain wiring

**Regression tests:** `src/context/__tests__/AgentSessionListContext.test.tsx` — 4 Vitest cases (SP7 block)
