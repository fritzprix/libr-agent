# Output Format Guidelines

## Week summary

```
📅 이번 주 일정 (6/9 – 6/15, Asia/Seoul) — 5건

  월 09:00  팀 스탠드업          30m
  화 15:00  Design review        1h   Zoom
  수 10:00  1:1 with Alex        30m
  ...

다음: "화요일 미팅 상세 보여줘" / "목요일 2시에 슬롯 잡아줘"
```

Group by day; show title, time, location when present.
